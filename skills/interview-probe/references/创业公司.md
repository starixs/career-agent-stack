# 创业公司拷打手册（精简版）

> 适用：早期到 B/C 轮的创业公司、小团队。面试官往往是创始人、合伙人或业务一号位。

## 面试官画像

面试官多半是创始人本人或早期核心，没受过标准面试训练，但商业嗅觉极敏锐，而且每一个 headcount 都是自己的钱。他们不在乎你的方法论体系，在乎的是你来了能不能直接干活、出活，活儿杂的时候跑不跑。风格跳跃、不按套路、经常打断，问题更像聊业务而不是面试。

## 嘴上问的 vs 心里验证的

| 嘴上问 | 心里在验证 |
|--------|-----------|
| 这个项目就你一个人做的吗？ | 离开大平台的资源，你还剩多少战斗力 |
| 没有数据团队你怎么办？ | 动手能力，是不是只会提需求的"流程人" |
| 一个人要干三个人的活，你怎么看？ | 嫌不嫌活杂活脏，会不会三个月就跑 |
| 你觉得我们产品有什么问题？ | 真研究过没有，敢不敢说真话 |
| 为什么从大厂出来？ | 主动选择还是混不下去，预期管理做没做 |

## 特有刀法

1. **剥平台刀**：对大厂背景候选人的头号刀，验证能否分清"平台的能力"和"自己的能力"。示例："这个增长离开了大厂的流量池和中台，还能复现吗？"
2. **动手刀**：对"我推动了""我协调了"过敏，想听的动词是"我做了"。示例："这个数据是你自己跑的还是提需求让别人跑的？SQL 写吗？"
3. **下沉刀**：描述一个又杂又脏的场景试探第一反应。示例："下个月可能要你去客服轮岗一周接用户电话，OK 吗？"
4. **真话刀**：敷衍夸的扣分，提得浮的说明没真用过，提得狠且在理的加分。示例："你觉得我们产品哪里做得不行？"
5. **算账刀**：创始人天天在算账，大厂候选人习惯谈指标不谈钱。示例："你做的这件事折算成本多少，赚回来了吗？"

## 轮次差异

- **业务面（合伙人/一号位）**：剥平台刀 + 动手刀为主，锁定简历里最依赖平台资源的成果钻。
- **老板面（创始人）**：真话刀 + 下沉刀 + 动机，反复从不同角度试探"你为什么来、能待多久"；对"看好这个赛道"追："说一个我们打不过竞品的点。"
- **HR 面**：多数没有独立 HR 面，有则并入老板面谈钱。重点拷期权认知（"现金比大厂低、用期权补，你怎么看期权价值？"）和预期管理（"一年内没有涨薪晋升体系，介意吗？"）；对期权一问三不知的记为高危信号。

## 钻探示范

Claim（大厂背景候选人）："从 0 到 1 搭建了内容审核体系"

1. 从 0 到 1，这个 0 是真的什么都没有，还是中台已有审核能力、你做的是业务接入？
2. （承认有中台）那你自己做的部分具体是什么？
3. 【杀招·剥平台】来我们这，没有中台、没有标注团队、预算只够两个人，这套体系你怎么搭？
4. 【杀招·动手】策略规则是你自己写的吗？还是你写文档、别人配置？
5. 【杀招·算账】这套体系当时投入了几个人、多少钱，拦住了多少损失？
6. 【杀招·下沉】早期没有审核工具，可能要你自己人肉审一段时间，你干吗？
