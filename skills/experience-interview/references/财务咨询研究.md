# 财务、咨询与研究类经历访谈手册

适用：财务 / 会计 / 审计 / 税务 / FP&A；战略咨询 / 商业分析；行业研究 / 投资研究 / 投行 / 风控 / 量化研究。

## 证据载体

| 载体 | 强度 | 说明 |
|---|---|---|
| 研究报告 / 纪要 / 点评原件（署名或贡献说明） | 强 | 研究岗核心产出 |
| 财务模型文件（三表、估值、预算） | 强 | 能看出独立搭建的部分 |
| 审计底稿、函证记录、盘点表 | 强 | 需脱敏，证明执行过程序 |
| 报表、对账记录、凭证处理量统计 | 中 | 财务核算证据 |
| 项目交付物 PPT、访谈纪要（咨询） | 中 | 需补个人负责章节 |
| 数据库取数记录（Wind / iFinD / Choice） | 中 | 证明亲手处理数据 |
| 被采纳记录：邮件反馈、上会材料引用 | 中 | 证明产出被使用 |
| 证书成绩单（CPA 科目、CFA 级别） | 中 | 已通过部分才算 |
| 竞赛报告、模拟盘记录 | 弱 | 不得写成正式投研业绩 |
| 口头"参与了某 IPO 项目" | 弱 | 标 pending，追问具体分工 |

## 评价指标

1. 研究覆盖：行业 / 公司 / 产业链环节数量、跟踪频率、周期
2. 产出数量：报告篇数、纪要期数、页数（只是产出量，还需补用途）
3. 模型：表数、行数、估值方法名、是否被采纳
4. 项目：数量与类型（IPO / 并购 / 年审 / 尽调）、金额量级、客户行业
5. 处理量：凭证 / 发票数、报表周期、预算金额
6. 分析被采纳：改了什么决策、省了多少钱或多赚多少（怎么算的）
7. 数据口径：单位（万 / 亿 / bps / pp）、同比环比、净额总额三全
8. 访谈数量、研究范围（行业数、公司数）
9. 审计：科目 / 循环、样本量、发现问题数
10. 风控：监测量、预警准确率、处置案件数
11. 量化：回测区间、股票池、夏普、回撤、是否计交易成本

## 术语

- 三表：利润表 / 资产负债表 / 现金流量表
- DCF：现金流折现估值
- 可比公司法：相对估值
- EBITDA：息税折旧摊销前利润
- WACC：加权资本成本
- 市盈率 / 市净率：PE / PB
- 同比 / 环比：YoY / QoQ
- bps / pp：基点 / 百分点
- 函证：向第三方确认
- 底稿：审计工作记录
- 截止性测试：期间归属检查
- 重要性水平：审计误差阈值
- 收入确认：确认收入时点
- 进项转出：增值税调整
- 月结：月度结账
- 账龄：应收账款时长
- 尽调：尽职调查
- 招股书：IPO 文件
- 产业链：上下游环节
- 催化剂：推动股价事件
- 覆盖：持续跟踪研究
- 假设树：咨询分析框架
- MECE：不重不漏
- 回测：历史数据验证
- 因子：选股变量
- 风控规则：风险判断逻辑

## 追问清单

**业务背景**
1. 你所在的组 / 条线做什么业务？研究成果交给谁用（投资经理、客户、管理层）？
2. 研究或审计的对象是哪个行业、哪家公司、哪个科目？

**规模数据**
3. 覆盖了多少家公司 / 多少期报告 / 多少凭证？周期多长？
4. 项目金额量级、模型规模、样本量各是多少？

**个人贡献**
5. 报告 / 模型 / 底稿里哪部分是你独立完成的？哪些是在指导下执行的？
6. 数据是你自己从数据库取的，还是别人给的？

**成果**
7. 你的产出被采纳了吗？谁用了、用在哪一步、有什么反馈？
8. 你形成过什么判断？后来被验证或修正了吗？

**困难与解决**
9. 处理过口径冲突或数据不一致吗？怎么核验的？
10. 函证不符 / 客户不配合 / 数据缺失时你怎么处理的？上报了吗？

**关键判断**
11. 估值方法、分析框架当时有哪些选择？为什么用这个？
12. 有没有你发现问题并推动改变的例子？

**降级问法**
- 「没有行业研究经历」→ 课程里写过行业分析报告吗？自己炒股有持续的研究笔记或交易记录吗？
- 「没进过事务所」→ 做过学生组织的财务、报销对账、社团预算吗？处理过多少笔？

> 本手册为通用归纳，具体口径以用户实际工作为准
