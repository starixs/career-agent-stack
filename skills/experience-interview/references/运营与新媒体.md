# 运营与新媒体类经历访谈手册

适用：内容 / 用户 / 活动 / 社区 / 电商 / 短视频 / 私域运营，公众号、小红书、抖音等账号运营。

## 证据载体

| 载体 | 强度 | 说明 |
|---|---|---|
| 平台后台数据截图（阅读、播放、涨粉、转化） | 强 | 要能对应到时间段 |
| 活动复盘文档（目标、投入、结果、改进） | 强 | 证明跑过完整闭环 |
| 增长看板 / SQL 取数记录 | 强 | 证明亲手看过数据 |
| 发布的内容本身（文章、视频链接及数据） | 中 | 需说明是否独立产出 |
| 活动方案、排期表、物料清单 | 中 | 证明策划参与 |
| 社群 / 企微 SOP 文档、触达记录 | 中 | 私域运营核心 |
| 投放后台（预算、ROI、消耗） | 中 | 涉及金额需本人确认 |
| 用户访谈记录、评论区反馈汇总 | 中 | 证明用户认知 |
| 校园活动签到表、推文后台 | 弱 | 学生素材，需补规模 |
| "发过 10 篇文章"无数据 | 弱 | 标 pending，追问阅读与转化 |

## 评价指标

1. 用户规模：参与人数 / 覆盖量 / 粉丝数，写清起点和终点
2. 增长数据：新增、留存率（次留 / 七留 / 三十留口径）、转化率
3. 内容产出：篇数 / 条数、平均阅读或播放、爆款率（不是只报一条爆款）
4. 活动效果：GMV 或转化提升幅度，必须说对比基准与同期大盘
5. 补贴与 ROI：投了多少、回了多少、不投补贴还剩多少
6. 获客成本：每个新用户多少钱、能否规模化
7. 私域：社群数、活跃率、掉粉率、触达频次
8. 电商：坑产、动销率、退货率、客单价
9. 短视频：完播率、互动率、投流 ROI、自然流占比
10. 从 0 到 1 还是接手优化：两者数字含义不同

## 术语

- 拉新：获取新用户
- 促活：提升活跃
- 留存：用户持续使用
- 召回：唤回流失用户
- 转化率：完成目标比例
- GMV：成交总额
- ROI：投入产出比
- 自然流量：非付费流量
- 投流：付费推广
- 完播率：看完比例
- 爆款率：高表现内容占比
- 私域：自有触达渠道
- SOP：标准操作流程
- 企微：企业微信
- 坑产：单位坑位产出
- 动销率：有销售的 SKU 占比
- 客单价：单客平均消费
- 大盘：整体基准数据
- 对照组：未干预对比样本
- 用户分层：按行为分群
- KOC / KOL：关键意见消费者 / 领袖
- 选题：内容主题策划
- 人设：账号定位

## 追问清单

**业务背景**
1. 这个账号 / 活动 / 社群服务谁？你接手时是什么状态（粉丝数、活跃度）？
2. 目标是拉新、促活、转化还是品牌？谁定的目标？

**规模数据**
3. 起点和终点的核心数字各是多少？周期多长？
4. 投入了多少预算、多少人、多少条内容？

**个人贡献**
5. 选题、文案、拍摄、剪辑、投放、数据复盘，哪些是你自己做的？
6. 团队几人？你负责哪一段？

**成果**
7. 提升幅度和什么比？同期大盘涨了多少？有对照组吗？
8. 哪条内容数据最好？为什么？后面几条数据怎么样，复制成功了吗？

**困难与解决**
9. 数据最差的一次是什么情况？你怎么调整的？
10. 资源不够的时候（没预算、没设计）你怎么解决？

**关键判断**
11. 有没有你自己定的策略，而不是执行上级安排？依据是什么？
12. 复盘后第二次做改了什么？

**降级问法**
- 「没运营过账号」→ 自己发过小红书、B 站、公众号吗？哪怕只有几百粉，有持续记录就算。
- 「没做过活动」→ 社团、班级、学生会组织过什么？多少人参加、怎么宣传的？

> 本手册为通用归纳，具体口径以用户实际工作为准
