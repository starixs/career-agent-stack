# 市场与销售类经历访谈手册

适用：品牌 / 数字营销 / 公关 / 活动 / KOL 投放；B 端销售 / KA / BD / 客户成功 / 渠道；校园代理、兼职销售。

## 证据载体

| 载体 | 强度 | 说明 |
|---|---|---|
| 投放后台数据（预算、曝光、线索、ROI） | 强 | 金额需本人确认口径 |
| CRM 记录、商机阶段、签约合同 / 订单 | 强 | 销售岗核心证据 |
| Campaign 复盘报告 | 强 | 证明操盘而非执行 |
| 业绩排名表、完成率通报 | 强 | 需附团队人数 |
| 媒体稿件、发布链接、公关监测报告 | 中 | 公关岗证据 |
| 达人合作清单与数据 | 中 | 证明选号与复投判断 |
| 客户拜访记录、方案 PPT | 中 | 证明拿单过程 |
| 活动物料、现场照片、签到数据 | 中 | 需补转化数据 |
| 校园代理的销售记录、提成单 | 弱 | 学生素材，需量化 |
| "发了 100 封开发信"无转化 | 弱 | 标 pending |

## 评价指标

1. 预算与 ROI：经手多少钱、回了多少、获客成本
2. 曝光到转化的后链路：曝光 → 线索 → 注册 / 购买各层数字
3. 业绩：完成率、团队排名、客单价、成交周期、赢单率
4. 客户数：开发多少、维护多少、新客占比（自己开的还是公司给的）
5. 续约 / 复购率、回款情况、坏账
6. 渠道数量与类型，各渠道效率
7. 达人投放：复投率、单个达人 ROI、数据水分判断方法
8. 公关：发稿量、核心媒体覆盖、负面处置时效
9. 活动：参与人数、成本、转化
10. 预算砍半时的应对（面试必问，提前问清）

## 术语

- Campaign：营销战役
- CPM / CPC / CPL：千次曝光 / 点击 / 线索成本
- ROI：投入产出比
- 线索：潜在客户信息
- 转化：完成目标动作
- 品效：品牌与效果
- KOL / KOC：意见领袖 / 消费者
- 复投：再次投放
- 蒲公英 / 星图：达人平台
- 比稿：代理公司竞标
- 通稿：公关统一稿件
- 舆情：公众评价态势
- KA：大客户
- BD：商务拓展
- 商机：潜在成交机会
- 决策链：客户购买角色
- 赢单率：成交比例
- 回款：收到货款
- 续约率：客户续签比例
- NDR：净收入留存
- 返点：渠道奖励
- Pipeline：商机储备
- Forecast：业绩预测

## 追问清单

**业务背景**
1. 卖的是什么产品、面向什么客户？市场活动的目标是曝光、线索还是销售？
2. 你所在团队几个人，分别管什么？

**规模数据**
3. 经手预算多少？带来多少曝光、线索、成交？
4. 年度指标多少？完成率多少？团队平均多少，你排第几？

**个人贡献**
5. 创意、投放、达人沟通、数据复盘，哪些是你做的，哪些是代理公司做的？
6. 最大的一单客户是公司分配的线索还是你自己开发的？

**成果**
7. 获客成本多少？在行业里算什么水平？
8. 客户后来续约 / 复购了吗？

**困难与解决**
9. 丢过印象最深的单 / 效果最差的一次投放是什么？为什么？
10. 遇到过负面舆情或客户投诉吗？谁拍的板，你做了什么？

**关键判断**
11. 选达人 / 选渠道时除了粉丝量还看什么？怎么判断数据有没有水？
12. 预算被砍一半时你砍了什么、保了什么？

**降级问法**
- 「没做过营销」→ 社团招新、校园活动的宣传是你做的吗？几篇推文、多少人报名、花了多少钱？
- 「没做过销售」→ 做过校园代理、兼职推销、帮家里生意谈过客户吗？卖了多少、提成多少？

> 本手册为通用归纳，具体口径以用户实际工作为准
