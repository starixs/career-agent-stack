# 教育与内容类经历访谈手册

适用：教师 / 助教 / 培训师 / 教研 / 课程设计；编辑 / 文案 / 撰稿 / 翻译 / 内容策划；家教、支教、知识类自媒体。

## 证据载体

| 载体 | 强度 | 说明 |
|---|---|---|
| 课件、教案、题库原件（署名） | 强 | 教研核心产出 |
| 学员成绩 / 通过率前后对比 | 强 | 需说明样本与周期 |
| 发表的文章、书稿、译稿及链接 | 强 | 带阅读量更好 |
| 学员 / 家长评价、满意度数据 | 中 | 需附人数与渠道 |
| 课程录播、公开课记录 | 中 | 证明授课能力 |
| 编辑记录：选题单、审稿意见、改稿版本 | 中 | 证明编辑贡献 |
| 内容后台数据（阅读、完读、转化） | 中 | 内容运营方向 |
| 支教 / 志愿时长证明、机构证明 | 中 | 需补具体教学内容 |
| 家教的学生提分记录 | 弱 | 口述为主，需本人确认 |
| "写过很多文章"无链接 | 弱 | 标 pending |

## 评价指标

1. 教学规模：带过多少学生 / 班级、多少课时、多长周期
2. 效果：提分幅度、通过率、续费率（说清对比基准）
3. 课程产出：开发了几门课、多少课时、多少题目
4. 学员反馈：评分、好评率、投诉率
5. 内容产出：篇数 / 字数、发表平台、阅读量 / 完读率
6. 编辑质量：错误率、返稿率、出版周期
7. 翻译：字数、领域、交付周期、审校通过率
8. 教研：教材 / 教案被采用的范围（几个班、几个校区）
9. 续班 / 转化：试听转正式的比例
10. 独立授课还是助教：角色边界

## 术语

- 教案：单次课设计
- 课件：教学演示材料
- 教研：课程研发
- 大纲：课程框架
- 学情：学生学习状况
- 分层教学：按水平分组
- 续班率：学员续报比例
- 试听转化：试听后报名比例
- 满意度：学员评价得分
- 教学反思：课后复盘
- 题库：练习题集合
- 公开课：对外展示课
- 磨课：反复打磨课程
- 选题：内容主题确定
- 审稿：审核稿件
- 校对：文字纠错
- 排版：版面设计
- 完读率：读完比例
- 原创率：原创内容占比
- 稿费 / 千字：按字数计酬
- 译审：翻译后审校
- 术语表：翻译词汇统一

## 追问清单

**业务背景**
1. 教的是什么科目 / 写的是什么领域？面向什么学生或读者？
2. 机构 / 平台是什么性质、规模多大？

**规模数据**
3. 带过多少学生、多少课时？写了多少篇、多少字？
4. 周期多长？是持续的还是一次性的？

**个人贡献**
5. 课件 / 教案 / 稿件是你独立写的还是改编现成的？
6. 是独立授课还是助教？哪些环节由你负责？

**成果**
7. 学生成绩或通过率前后各是多少？内容阅读量 / 完读率多少？
8. 有没有被采用、被表扬、被续约、被转载的记录？

**困难与解决**
9. 遇到过听不懂、学不进、稿子被反复退改的情况吗？你怎么调整的？
10. 时间紧或资源少时怎么保证交付？

**关键判断**
11. 课程设计或选题上有没有你自己定的方向？依据是什么？
12. 第二次再做改了什么？

**降级问法**
- 「没当过老师」→ 做过家教、带过学弟学妹复习、在社团做过培训分享吗？多少人、多少次、效果如何？
- 「没发表过内容」→ 公众号、知乎、小红书、校媒写过稿吗？哪篇数据最好？

> 本手册为通用归纳，具体口径以用户实际工作为准
