# 风格库：公司性质决定证据排序

写作方法是骨架，公司性质只决定先展示什么证据、用什么语气。先做保真与价值翻译，再按目标公司选对应章节；冲突时以保真为准。使用顺序固定：通用方法 → 本文件对应公司章节 → 岗位速查对应岗位。例如"大厂行研"要同时叠加大厂与行研规则，"外企财务"叠加外企与财务两套。

## 券商 / 银行 / 金融机构

**一句话**：专业、严谨、数字精确。HR 用证书和课程验真，用数字口径判断你严不严谨。

证据排序：
1. 数字是信任货币：单位（万 / 亿 / bps / pp）、时间口径（同比 / 环比）、统计口径（净额 / 总额）三全；拿不准宁可不写。
2. 证书分级写：「通过 FRM 一级」「CFA 一级（备考二级）」，从业资格合并一行，证书栏靠前。
3. 课程是背书：列 3–5 门金融核心课，有高分可附分数。
4. 项目模型化：背景 → 个人负责模块 → 方法与数据源 → 产出与是否被采纳；术语必须准确。
5. 实习写专业动作：研究 / 风控 / 投行类突出独立交付物，操作类突出业务量与零差错。
6. 分支：中资大行向国央企规则靠；外资机构叠加外企规则，CFA / FRM 权重更高。

忌：「对金融充满热情」类空话、创新颠覆叙事、无量化的经历。

## 大厂（互联网 / 科技）

**一句话**：HR 几秒扫一份简历，数字是锚点，JD 的语言是通行证。

证据排序：
1. 每段经历至少 2 个数字：一个业务规模，一个个人产出。
2. 动词有力但保真：真主导才写「主导」，协助写「支持 / 配合推进」。
3. JD 关键词自然植入：一条 bullet 命中 1–2 个即可，堆砌会露馅。
4. 经历项目化：时间、背景、角色、动作、量化五要素齐，社团活动也这样写。
5. 归属写法：大集团子业务写「母公司 / 业务线」，独立小公司不挂靠。
6. 公司口味微调：字节看数据与实验思维；阿里看商业逻辑；腾讯看产品体验；美团 / 拼多多看实操落地；内容平台看你是不是深度用户。

忌：「责任心强 / 沟通能力强」类空话、工具图标堆砌、拿浅度大厂经历硬撑门面。

## 国央企

**一句话**：完整、稳重、能融入体系，与大厂逻辑几乎相反，同一份简历不能混投。

证据排序：
1. 信息求全：政治面貌必写（群众也写），籍贯、出生年月可写，教育信息全列。
2. 学生干部、志愿服务、社会实践是核心资产：前置展开写职务、任期、协调规模、活动清单。
3. 荣誉选主旋律：奖学金、优秀学生干部、挑战杯 / 互联网+ 权重高于商业比赛。
4. 语气谦逊：多用「参与 / 协助 / 在指导下完成」，数字要有但表述克制。
5. 技能保守写：Office 可拆开写，少列潮流工具与黑话。
6. 政审意识：全文零虚假，海外经历如实。

忌：颠覆 / 创新叙事、突出个人商业成就、体现「不稳定」的痕迹。

## 外企

**一句话**：STAR 结构 + 强动词 + 国际可读的量化；应届英文简历严格一页。

证据排序：
1. 每条 bullet 过去式强动词开头（Led / Built / Analyzed / Reduced），禁用 Helped / Assisted / Responsible for，全文不出现 "I"。
2. STAR 完整：背景、目标、动作、结果，结果必须量化。
3. 量化国际化：M / K 计数、YoY / QoQ、bps，币种按公司全球性选择。
4. Skills 分栏：Hard Skills / Tools（标熟练度）/ Languages（标分数）/ Certifications。
5. 国际信号前置：交换、全英文授课项目、外语等级、国际比赛。
6. 双语策略：英文版不是中文版直译，英文更直接、更突出 result。
7. Cover Letter 在咨询和外资金融权重高，「为什么是这家公司」必须具体到业务。

忌：Chinglish、时态混用、超页。
