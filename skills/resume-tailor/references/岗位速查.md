# 岗位速查：专业词与 bullet 结构

目标岗位决定用什么专业词、bullet 按什么结构讲。直接套用对应章节；未覆盖的岗位参考最接近的框架。所有 bullet 仍遵守「动作 + 落地方式 + 量化结果」，并且被追问三层不露馅。

## 行业研究 / 投资研究

**HR 在验证**：能否界定研究问题、找到可信数据并处理口径、从证据形成判断、把成果交付给真正使用它的人。

- 关键动作词：覆盖、跟踪、搭建（模型 / 数据库）、测算、形成判断、输出、验证
- 必量化维度：覆盖公司 / 产业链环节数、跟踪频率与周期、数据源、报告 / 纪要篇数、模型规模、采用情况
- bullet 结构：**研究对象 → 数据与口径 → 分析方法 / 判断 → 产出及用途**；可加第四条「更新与验证」
- 表述分寸：资料整理≠独立覆盖；未参与决策不写「推动建仓」；模拟盘 / 竞赛不写成真实业绩；趋势判断不写成确定预测

**不同去向，首要证明不同**：

| 去向 | 首要证明 | 优先展开 |
|---|---|---|
| 券商卖方 | 持续覆盖与稳定交付 | 覆盖范围、跟踪频率、数据源、纪要 / 点评 / 深度报告 |
| 买方研究 | 形成并验证投资判断 | 核心假设、催化剂、风险点、估值方法、跟踪验证 |
| 银行 / 金融机构研究 | 专业口径与风险意识 | 宏观 / 行业变量、风险口径、监管边界 |
| 企业战略 / 产业研究 | 把外部信息转成经营判断 | 市场空间、产业链位置、竞争格局、对规划的支持 |
| 大厂战略 / 商分 | 用数据回答具体业务问题 | 用户 / 商家场景、数据规模、指标、结论与验证 |
| 国央企产业研究 | 服务规划与政策理解 | 政策口径、产业链环节、对标单位、协同对象 |
| 外企 / 咨询研究 | 结构化解决问题 | 问题、假设、证据、洞察、建议、影响 |

**行业决定研究对象和指标**：周期 / 制造 / 新能源写供需、产能、价格、招标与成本；消费写品类、价格带、渠道、复购；TMT 写用户场景、渗透率、活跃留存、商业化；医疗写疾病领域、临床阶段、监管与支付；金融写利率、资产负债、信用风险、监管。行业词必须来自用户确实研究过的对象，JD 有而事实库没有的只能标缺口。

- 地雷：报告页数当研究价值；团队结论写成个人结论；估值方法、产业链环节、医学术语写错；为贴 JD 虚构访谈、问卷、实地调研

## 投资银行 IBD

**HR 在验证**：项目真实性、建模能力、行业覆盖、抗压信号。
- 关键动作词：协助完成、搭建模型、撰写材料、尽调、对接、整理
- 必量化维度：项目数量与类型（IPO / 再融资 / 并购）、金额（亿元级）、模型表数、材料页数
- bullet 结构：**项目类型与规模 → 具体分工 → 交付物 → 项目结果**
- 表述分寸：实习生写「协助 MD / VP 完成」，保密信息用「某 A 股上市公司」
- 地雷：夸大职责；EBITDA / FCF / WACC 用错；项目时间线与公开信息不符

## 风险管理 / 风控

**HR 在验证**：风险意识、数据敏感度、合规思维、异常判断力。
- 关键动作词：监测、识别、预警、审核、制定规则、降低、控制
- 必量化维度：监测数据量、预警准确率 / 召回率、处置案件数、损失下降幅度
- bullet 结构：**风险场景 → 监测 / 识别方式 → 处置动作 → 量化效果**
- 表述分寸：强调合规、及时、准确；具体阈值不写
- 地雷：把拒绝率当正面指标；只写技术不写业务影响；把风控等同催收

## 审计（四大 / 内资所）

**HR 在验证**：项目完整性、准则熟悉度、抗压、细节严谨。
- 关键动作词：执行（测试 / 程序）、核对、函证、盘点、编制底稿、复核
- 必量化维度：项目数量与类型、客户行业、样本量、底稿页数
- bullet 结构：**项目类型与客户规模 → 负责科目 / 循环 → 执行程序 → 发现问题或结论**
- 表述分寸：「在项目组指导下执行」，客户用「某制造业上市公司」
- 地雷：实习生写「出具审计报告」；科目 / 准则名写错；时间与 busy season 不符

## 数据分析

**HR 在验证**：数据规模、工具真实熟练度、能否给出业务结论。
- 关键动作词：取数、拆解、建模、验证、输出结论、推动
- 必量化维度：多少条 / 家 / 表 / 周期；结论挂业务指标（收入 / 留存 / 转化），不挂技术指标
- bullet 结构：**业务问题 → 方法与数据量 → 量化发现 → 业务影响**
- 表述分寸：工具 3–5 个标熟练度，Excel / SQL 不单列；机器学习写清算法名
- 地雷：A/B≠简单对比；相关≠因果；EDA 说成建模；只写工具不写数据量

## 量化研究 / 量化策略

**HR 在验证**：编程能力、市场理解、因子思路、回测规范、业绩真实性。
- 关键动作词：构建、挖掘、回测、优化、跟踪、实现
- 必量化维度：因子数、回测区间、股票池规模、收益 / 夏普 / 最大回撤、数据频率
- bullet 结构：**策略类型 → 因子来源 / 逻辑 → 回测表现 → 改进措施**
- 表述分寸：回测写清区间、基准、是否计成本；学生写「课程 / 竞赛项目」不写「实盘」
- 地雷：只写收益不写回撤；未剔除未来函数；课程作业包装成团队项目

## 产品经理

**HR 在验证**：用户视角、需求定义、推动落地、数据 sense。
- 关键动作词：定义、设计、推动、上线、验证、迭代
- 必量化维度：用户 / 场景规模、协调人数与周期、上线后指标变化、迭代版本数
- bullet 结构：**用户 / 场景 / 痛点 → 方案设计 → 推动落地 → 业务指标变化**
- 表述分寸：方法论词（用户画像、KANO）真用过才写；跨部门写「协调 N 人、X 周上线」
- 地雷：只讲功能不讲用户；只写上线不写数据；「提需求」说成「产品设计」

## 运营（内容 / 用户 / 活动）

**HR 在验证**：真实操盘项目、数据结果、资源调动、用户感知力。
- 关键动作词：策划、执行、推广、转化、增长、拉新、促活、留存
- 必量化维度：用户规模、增长数据（新增 / 留存率 / 转化率）、内容产出量与数据、活动 ROI
- bullet 结构：**目标 → 方案（渠道 + 玩法）→ 执行（资源 + 周期）→ 结果（数据）**
- 表述分寸：写清「从 0 到 1」还是「接手后优化」
- 地雷：只写做了什么不写数据；「发了 10 篇」没有阅读量；虚报数据

## 市场营销

**HR 在验证**：Campaign 操盘、品牌感知、渠道资源、ROI 意识。
- 关键动作词：策划、执行、投放、合作、传播、曝光、转化
- 必量化维度：预算与 ROI、曝光 / 触达、转化（线索 / 注册 / 购买）、渠道数量
- bullet 结构：**Campaign 目标 → 创意 / 渠道策略 → 执行与资源 → 曝光与转化数据**
- 表述分寸：真实投放经验哪怕预算很小也写清
- 地雷：只写创意不写数据；「转发海报」说成「市场推广」；虚报预算

## 战略 / 咨询

**HR 在验证**：结构化思维、商业洞察、PPT 能力、项目真实性。
- 关键动作词：分析、梳理、访谈、研究、建议、输出
- 必量化维度：项目数量与类型、访谈对象数、研究范围、交付物页数
- bullet 结构：**项目背景与目标 → 分析框架 / 方法 → 关键发现 → 交付物与影响**
- 表述分寸：「在项目组支持下完成」；客户脱敏
- 地雷：「做了 PPT」说成「战略咨询」；只写框架不写洞察；虚构访谈对象

## 财务

**HR 在验证**：准则熟悉度、分析能力、系统操作、严谨度。
- 关键动作词：核算、编制、审核、分析、预测、对账、报税
- 必量化维度：凭证 / 发票数、报表类型与周期、预算金额、成本节约金额
- bullet 结构：**财务模块 → 具体工作 → 处理量 / 金额 → 发现问题或优化结果**
- 表述分寸：证书写「CPA（已过 N 科）」；系统写具体模块
- 地雷：科目名写错；「录凭证」包装成「财务分析」；金额与公司规模不匹配

## 销售 / BD

**HR 在验证**：业绩真实性、客户资源、谈判能力、结果导向。
- 关键动作词：开发、维护、拓展、谈判、签约、达成、推进
- 必量化维度：客户数、签约金额 / 订单数、完成率、续约 / 复购率
- bullet 结构：**客户类型 → 开发 / 维护动作 → 成交结果 → 超额完成或续约**
- 表述分寸：区分公司分配线索与自主开发
- 地雷：只写客户数不写成交额；「发了 100 封开发信」没有转化；虚报业绩
