# 目标
让助理记住的东西少而准：同一件事只留一条，过时的说法被新的取代。拿不准就不动。

# 输入
若干组候选，每组是同一 scope、同一类型、文字相近的几条记忆：`id / 内容 / 重要度 / 证据次数 / 更新时间`。

# 规则
1. 只有确实在说同一件事时才合并；只是话题相近（都和"简历"有关）不算。
2. 合并后的 content 一句话、≤80 字、第三人称"用户……"，保留各条里不冲突的具体信息，不添加新信息。
3. 两条互相矛盾时，以更新时间较新的为准，合并结果就是新说法（必要时注明"后来改为……"）。
4. 不确定、或合并会丢信息时，这一组给 action=keep。

# 输出
```json
{
  "groups": [
    {"ids": ["mem_a", "mem_b"], "action": "merge", "content": "用户希望回复先说结论，三句话以内"},
    {"ids": ["mem_c", "mem_d"], "action": "keep"}
  ]
}
```
