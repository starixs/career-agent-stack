# 大厂复盘手册（精简版）

> 使用前提：以下是市场常见情况的归纳，不是规律；引用时必须写"可能"，并附至少一种其他解释。同一个动作在不同公司、不同面试官、不同岗位紧急程度下可能有完全不同的原因。

## 可观察事实与解释

| 可观察事实 | 一种可能的解释 | 其他可能 |
|---|---|---|
| 主动介绍团队构成、汇报关系、业务阶段 | 可能在向候选人介绍岗位，常见于有意推进时 | 也可能是该面试官的固定开场习惯，或公司要求统一说明背景 |
| 问 base 地能否接受、最快到岗时间 | 可能进入了可行性核算 | 也可能是标准信息采集，部分公司每场都问 |
| 问目前面了哪几家、进度如何 | 可能在评估时间窗口 | 也可能是了解求职阶段的常规问题 |
| 面试明显超时 | 可能对候选人有兴趣 | 也可能是当天排期宽松，或前面的题展开得慢 |
| 主动说下一轮是谁、大概什么时候 | 相对具体，通常和推进相关 | 也可能只是回答候选人提问，或流程本就固定公开 |
| 反问环节给足时间并认真回答 | 可能有争取意图 | 也可能是候选人体验考核的要求 |

## 信息量较低的表述

大厂普遍对面试官有候选人体验要求，友好和鼓励是流程动作，成本很低，不宜作判断依据：

- "你的背景挺不错的"
- "回去等通知""HR 会联系你"
- "你还有什么想问的吗"（固定环节）
- 全程微笑、态度友好
- 准时在预定时间结束（中性）

相对不利的观察：明显提前结束且全程没有验真型追问；问完一题直接跳下一题；反问环节只给一个问题的时间。同样要给其他解释：面试官当天有急事，或这一轮本就定位为快速筛选。

## 诊断检查项

大厂面试官多是一线业务骨干，见过大量包装过的简历。按四项检查：

1. **数据口径（`content:metric-definition`）**：报了数字有没有说清怎么算。留存提升 15% 是次日还是 7 日、新用户还是全量、分母有没有变。面试官追问口径而用户答不上，通常是本场分量较重的问题，优先级高于表达问题。
2. **归因（`content:attribution`）**：追问同期大盘走势、如何剥离自然增长、有没有 AB 实验，都属验真型追问。社招场次把团队成果直接说成个人成果，通常是重度失分。
3. **方法论的边界（`content:decision-rationale`）**：用户说"我有一套方法"，面试官追"什么情况下会失效"。答不出边界，一种可能是说法主要为面试准备；也可能平时确实在用但没把边界语言化。
4. **跨部门推动的细节（`content:personal-contribution`）**：真推过的人说得出拉了什么会、找了谁、置换了什么资源、何时升级。只说"积极沟通"，可能缺实际经验，也可能出于保密没展开。

表达层常见问题（`delivery:missing-context`）：讲项目不交代背景直接进细节，面试官不熟悉前司业务，听不懂往往给中间分。

## 等待周期参考

仅供判断是否继续等待，**不能反推面试结果**：

- 一面到二面：常见 2 到 5 个工作日
- 终面之后：常见 1 到 2 周
- 超出较多：可能流程暂停，原因可能是评估未通过、名额调整、内部候选人优先、审批延迟等，候选人侧无法区分

建议：把等待当作推进其他机会的时间。大厂普遍有人才库机制，本次未成不影响后续重投。

## 材料缺失时可补问

- 报数字时面试官有没有要求解释计算方式
- 有没有问"如果数据是跌的你会怎么办"这类假设题
- 有没有问目前的面试进度
- 有没有主动讲团队现在在做什么
- 结束语的原话是什么
