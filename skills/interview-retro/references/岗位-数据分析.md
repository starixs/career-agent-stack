# 数据分析岗复盘手册（精简版）

> 涵盖：业务分析 / 商业分析 / BI / 增长分析

## 面试官在验什么

1. **技术是门槛，业务是上限。**SQL 会不会是筛子，能不能把分析变成决策才是评分点。
2. **分析有没有被采纳。**做了一堆报表没人用，和推动了一个决策，是两个级别。
3. **归因的严谨性。**最忌把相关当因果，面试官会专门下钩子。
4. **数据敏感度。**给一个反常的数，能不能立刻想到几种可能原因。

## 高频追问链

**链一：分析项目**
讲个你做过的分析 → 结论是什么 → 怎么排除其他解释的 → 有没有做实验验证 → 业务方采纳了吗 → 后来结果怎么样
（分水岭在第三层：答不出排除逻辑，`content:attribution` 成立）

**链二：指标异常（现场题）**
某指标突然跌 20%，你怎么查 → 先看什么 → 怎么拆维度 → 如果各维度都跌呢 → 怎么排除数据本身的问题
（考思路结构，不是答案对错；分水岭在第三层）

**链三：技术深度**
这个数怎么取的 → 表是哪来的、有没有脏数据 → 窗口函数 / 留存怎么算 → 数据量大时怎么优化

## 专业性检验点

- 留存怎么算，次留 / 七留 / 三十留的口径分别是什么
- 窗口函数的实际使用场景
- AB 实验怎么设计，样本量怎么定，显著性怎么判
- 数据不一致怎么定位
- 用什么 BI 工具，指标口径归谁管
- 增长：漏斗怎么拆，每层转化基准是多少

## 与企业性质叠加

- **大厂**：实验设计和统计严谨性追得最深，可能问 p 值、功效、AA 测试
- **创业公司**：数据基建差，问没有数仓时怎么干活
- **国企 / 银行**：更关注准确性、报送规范、口径一致性，实验类问题少
- **外企**：可能要求英文讲分析逻辑，`language:` 类标签单独记
