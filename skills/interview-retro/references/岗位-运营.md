# 运营岗复盘手册（精简版）

> 涵盖：内容 / 用户 / 活动 / 社区 / 电商 / 短视频 / 私域运营

## 面试官在验什么

1. **这个数是不是你做上去的。**运营最容易借势（大促、平台给量、竞品出事），面试官的核心任务是剥掉外部因素。
2. **有没有闭环。**跑过完整闭环的人说得出复盘、说得出第二次怎么改。
3. **对用户的具体认知。**能不能说出一类用户的真实行为，而不是"年轻女性、消费能力强"。
4. **执行密度。**运营是体力活，面试官会验证你自己干了多少。

## 高频追问链

**链一：活动效果**
活动做得怎么样 → GMV 提升 30% 是和什么比的 → 同期大盘涨了多少 → 有没有对照组 → 补贴投了多少、ROI 算过吗 → 不投补贴还有多少
（多数人卡在第三或第四层；答不出对照或大盘，`content:attribution` 成立）

**链二：用户增长**
拉新怎么做的 → 这批用户次留多少 → 七留、三十留呢 → 留下来的和自然新增有什么差别 → 获客成本多少 → 能不能规模化
（只说得出拉新量、说不出留存和成本，说明只做了投放执行；分水岭在第二层）

**链三：内容 / 短视频**
哪条爆了 → 为什么爆 → 你复制成功了吗 → 后面几条数据怎么样 → 爆款率多少
（分水岭在第三层：一条爆款可能是运气，能复制才是能力）

## 特有丢分点

| 表现 | 标签 | 说明 |
|---|---|---|
| 报 GMV、UV、增长率但说不清口径和对比基准 | `content:metric-definition` | 运营岗最高频失分 |
| 把平台流量、大促红利算成个人成果 | `content:attribution` | 面试官会直接问同期大盘 |
| 只讲做了什么，不讲复盘和迭代 | `content:decision-rationale` | 没跑过完整闭环 |
| 用户画像全是标签词，说不出具体行为 | `delivery:vague-language` | 没真的看过用户 |
| 通篇"我们团队做了"，问到分工答不上 | `content:personal-contribution` | 运营协作多，这一问必来 |

## 专业性检验点

- 负责的核心指标是什么、怎么定义、周报看哪几个数
- 拉新 / 促活 / 留存 / 召回，主要在哪一段
- 用什么工具看数据，有没有自己写 SQL 或提取数需求
- 一场活动从立项到上线过哪些环节，最常卡在哪
- 私域：企微、社群、SOP、触达频次、掉粉率
- 电商：坑产、动销率、退货率、客单、履约
- 短视频：完播率、互动率、投流 ROI、自然流占比

## 与企业性质叠加

- **大厂**：口径和归因追得最凶，`content:metric-definition` 优先级最高
- **创业公司**：问预算受限时怎么做，看成本意识
- **国企 / 银行**：更看重活动合规性、审批流程、对外口径稳妥，数据要求反而低
- **外企**：追问个人贡献（we/I）和跨区域协作怎么推动
