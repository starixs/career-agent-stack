# 市场营销岗复盘手册（精简版）

> 涵盖：品牌 / 数字营销 / 内容营销 / 公关 / 活动 / KOL 投放

## 面试官在验什么

1. **花钱的效率。**市场是花钱部门，第一关心预算用得值不值。
2. **品效之间的取舍。**只会讲曝光和声量，容易被判定为不懂生意。
3. **供应商和资源的掌控力。**能不能压价、能不能协调、出事能不能兜住。
4. **审美和判断的具体性。**说不出为什么这个 campaign 好，说明在执行别人的判断。

## 高频追问链

**链一：campaign 效果**
做得怎么样 → 曝光多少，然后呢 → 带来多少线索或转化 → 获客成本多少 → 预算多少，这个成本在行业算什么水平 → 如果预算砍一半你怎么做
（分水岭在最后一层：考取舍不是执行；第三层答不出后链路也常见）

**链二：KOL / 投放**
怎么选的达人 → 除了粉丝量还看什么 → 怎么判断数据有没有水 → 复投了吗 → 哪个达人 ROI 最高、为什么
（分水岭在第三层）

**链三：公关 / 危机**
遇到过负面吗 → 怎么处理的 → 谁拍的板、你做了什么 → 结果如何 → 事后有没有建机制

## 特有丢分点

| 表现 | 标签 | 说明 |

## 专业性检验点

- 经手的年度预算大概多少，怎么分配
- CPM、CPC、CPL、ROI 日常盯哪个
- 各投放平台的特点和适用场景
- 品牌类项目怎么衡量效果，用什么替代指标
- 和代理公司怎么合作：比稿、结算、KPI
- 公关：媒体资源怎么维护，通稿和深度稿的差别

## 与企业性质叠加

- **大厂**：效果导向强，一路追到转化和成本
- **创业公司**：预算极紧，重点问低成本获客和自然流量
- **国企 / 银行**：合规和口径审批是核心，对外发声流程比创意重要
- **外企**：全球品牌规范、本地化尺度、总部对齐是高频考点
