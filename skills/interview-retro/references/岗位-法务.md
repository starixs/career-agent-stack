# 法务岗复盘手册（精简版）

> 涵盖：律所律师 / 企业法务 / 合规 / 知识产权 / 数据合规
>
> 说明：本手册用于复盘面试表现，**不对具体法律问题的答案做正误判断**。用户需要确认某个法律实务问题时，说明这超出复盘范围，建议咨询专业人士。

## 面试官在验什么

1. **能不能给结论。**最常见失分是只讲风险不给建议，业务方要的是能不能做、怎么做。
2. **风险判断的分寸。**过度保守和过度放行都是问题，中间那条线是核心能力。
3. **商业理解。**企业法务尤其看这个，只懂法条不懂生意的很难通过。
4. **实务经验的真假。**面试官会往具体条款和谈判过程追。

## 高频追问链

**链一：合同 / 项目**
经手过哪类合同 → 通常争议最大的条款是哪条 → 对方不让步怎么办 → 最后怎么平衡 → 业务方满意吗
（分水岭在第二层）

**链二：风险判断**
业务想做一件有法律风险的事，你怎么处理 → 如果领导支持业务呢 → 你会怎么留痕 → 风险落地了责任怎么划
（既考底线也考实务，一味说"不行"和轻易放行都失分；分水岭在第二层）

**链三：专业深度**
（提到某领域后）→ 这块最近的监管变化是什么 → 对业务有什么影响 → 你们做了什么调整

## 专业性检验点

- 主要处理哪类业务，合同量大概多少
- 争议解决走过诉讼还是仲裁，参与到什么程度
- 数据合规：个保法下的合规动作、跨境传输怎么处理
- 知识产权：商标布局、专利流程、侵权应对
- 合规：制度怎么落地、培训怎么做、有没有做过内部调查
- 律所转企业：为什么转，知不知道两边工作方式的差别

## 与企业性质叠加

- **大厂**：节奏快，看能不能在有限时间给可执行意见；新业务合规是热点
- **创业公司**：一人法务部，问能不能同时管合同、劳动、融资、知产
- **国企 / 银行**：程序合规、审批留痕、国资监管；监管报送、消保、反洗钱
- **外企**：总部合规政策与本地法律冲突的处理，英文合同能力
