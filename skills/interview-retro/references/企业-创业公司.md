# 创业公司复盘手册（精简版）

> 使用前提：以下是市场常见情况的归纳，不是规律；引用时必须写"可能"，并附至少一种其他解释。创业公司流程标准化程度低，个体差异比其他类型都大，解读要格外保守。

## 可观察事实与解释

| 可观察事实 | 一种可能的解释 | 其他可能 |
|---|---|---|
| 拿当前真实业务问题问你会怎么做 | 可能在试用候选人的思路 | 也可能面试官习惯用真实场景出题，与评价无关 |
| 创始人或 CEO 在早期轮次出现 | 创始人时间成本高，出现通常和岗位重要性相关 | 也可能公司规模小，创始人本来就面每一个人 |
| 主动讲融资进度、股权结构、期权池 | 可能在向候选人交底 | 也可能是标准公司介绍环节 |
| 问能否接受初期混乱、身兼多职 | 可能在做预期管理 | 也可能是每场必问的筛选项 |
| 聊到入职后前几个月要做什么 | 相对具体，通常和推进相关 | 也可能只是在说明岗位职责 |
| 面试变成双向讨论、征求你对方案的看法 | 可能在验证协作方式 | 也可能是面试官的沟通风格 |

## 信息量较低的表述

创业公司普遍话说得满，热情往往是团队文化而不是评价：

- "我们非常需要你这样的人"
- "我们发展很快，机会很多"
- 面试氛围轻松、像朋友聊天（普遍非正式）
- 加了微信（常规操作）

相对不利的观察：全程只讲愿景不问具体能力；对过往项目细节不感兴趣；一面就反复确认期望薪资且表现为难。

## 诊断检查项

面试官通常是创始人或核心成员，关心的不是候选人有没有注水，而是离开原平台后还剩什么；每个名额都是实际成本支出。

1. **平台因素的剥离（`content:attribution`）**："DAU 千万级"的量级来自公司流量基础。检查用户有没有意识到这一点，有没有主动给出资源受限情况下的成果。
2. **亲自动手的证据（`content:personal-contribution`）**：创业公司缺支持团队。回答全是"我推动 XX 团队完成"在此场景通常不加分。检查有没有自己拉数据、写文档、跑客户的具体动作。
3. **成本意识（`content:decision-rationale`）**：这件事投入多少钱、多少人、多长时间，产出多少。在大平台只对指标负责的候选人常答不上。
4. **对流程与资源的依赖（`delivery:tone-complaint`）**："这个应该由 XX 部门来做"类表述在此场景通常是明显减分项。

## 等待周期参考

创业公司的等待时间参考价值很低，**不能反推结果**。常见延迟原因：融资节奏变化、创始人出差、没有专职 HR、还在等其他候选人、岗位定义中途调整。

- 两周内没消息：常见情况
- 一个月左右：可以主动问进度，创业公司普遍不介意
- 主动跟进后仍无回复：此时才具备一定参考价值

建议：面创业公司时主动跟进的收益通常大于风险，这与大厂、国企不同。

## 材料缺失时可补问

- 面试官有没有拿他们当下的真实问题问你
- 有没有讲融资阶段、团队规模、现金流
- 有没有问成本相关的问题
- 面你的人是创始人、核心成员还是外部招聘
- 有没有谈到期权或薪资结构
