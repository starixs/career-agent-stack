# 坑点与提问模板

## 坑点清单写作要求

- 3–5 个具体坑点，每个 = **风险描述 + 证据（来源）+ 面试时怎么问**。
- 优先写和钱、合同、稳定性直接相关的坑：合同主体、社保主体、发薪准时性、试用期、外包 / 派遣、加班文化、裁员传闻。
- 坑点必须来自信号证据，不许编造；证据弱就写「需核实」，不升级成结论。
- 每条「面试怎么问」要能直接照着问，语气中性，不带指责。

## 常见坑点模板

| 坑点 | 风险描述 | 面试怎么问 |
|---|---|---|
| 合同主体与社保主体不一致 | 劳动合同签在关联公司或第三方，社保在另一家，维权和工龄计算受影响 | 「劳动合同和社保分别是和哪家主体签 / 缴的？」 |
| 外包 / 派遣 / 项目制 | 招聘方与实际用工方不同，福利、晋升、稳定性弱于正编 | 「这个岗位是正式编制、外包还是派遣？合同期限和续签条件是什么？」 |
| 试用期过长或薪资打折 | 试用期超法定上限、工资低于 80%，或试用期考核标准不明 | 「试用期多长、薪资比例多少？转正考核有书面标准吗？」 |
| 发薪延迟 | 有拖欠工资、延迟发薪记录 | 「发薪日是哪天？过去一年有没有延迟发薪的情况？」 |
| 裁员 / 降薪传闻 | 近期有收缩、降薪、团队解散讨论 | 「团队近一年人员规模变化如何？岗位是新增还是补缺？」 |
| 加班文化 | 大小周、长期加班且无加班费或调休 | 「平均每周工作时长？加班有加班费还是调休？」 |
| 竞业限制 | 普通岗位也要求签竞业，补偿金不明 | 「入职要签竞业协议吗？范围和补偿标准是什么？」 |
| 培训费 / 押金 / 扣证件 | 要求缴纳培训费、押金，或扣押证件（违法信号） | 「入职需要缴纳任何费用或提供证件原件吗？」 |
| 绩效口径不透明 | 薪资大比例挂绩效但无考核标准 | 「薪资结构里固定与绩效各占多少？绩效按什么标准评？」 |
| 经营状况不明 | 工商异常、法人频繁变更、诉讼多 | 「公司近一年业务和融资情况如何？主要客户稳定吗？」 |

## 默认面试提问清单（8 问，可增删）

1. 合同与哪家公司主体签署？社保公积金缴纳主体与比例？
2. 试用期多长、薪资结构？绩效是否有书面考核标准？
3. 近一年是否有裁员 / 降薪 / 欠薪？离职率如何？
4. 发薪日与延迟记录？
5. 正编 / 外包 / 项目制？合同期限与续签条件？
6. 加班频率与加班费 / 调休政策？
7. 公司近一年诉讼 / 仲裁情况？经营现金流？
8. 直属上级与团队规模、汇报关系？

按公司情况增删：命中哪类信号，就把对应坑点的问法前置。

## 人工核实清单模板

每条写清「核什么、去哪核、为什么自动查不了」，用户照着做：

```
## 需人工核实
- [ ] 被执行 / 失信记录 —— 中国执行信息公开网，按工商全称查询（需验证码，无法自动核验）
- [ ] 经营异常 / 行政处罚 —— 国家企业信用信息公示系统（需验证码 + 登录）
- [ ] 劳动争议判决 —— 裁判文书网，搜「公司全称 + 劳动争议」（需登录）
- [ ] 同名主体确认 —— 按招聘信息里的城市 / 地址核对工商全称（搜索结果有 N 个同名候选）
- [ ] 员工评价原文 —— 看准 / 脉脉入口链接（只给入口，不抓原文）
- [ ] 关联方风险 —— 集团母公司「某某」有 X 记录，需判断与招聘主体的关联度
```

规则：未验证项一条都不能删；用户核实后给出的反证可以推翻红线，报告里注明。
