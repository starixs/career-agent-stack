# 法务出题手册（精简版）

> 涵盖：律所律师 / 企业法务 / 合规 / 知识产权 / 数据合规
>
> 本手册不判定法律答案对错，出题时标注 probe_points 而不是标准答案。

## 面试官在验什么

1. **能不能给结论**：最常见失分是只讲风险不给建议，业务方要的是能不能做、怎么做。
2. **风险判断的分寸与商业理解**：过度保守和过度放行都是问题；只懂法条不懂生意的很难通过企业法务面。
3. **实务经验的真假**：做过和看过差别很大，会往具体条款和谈判过程追。

## 高频追问链

**链一：合同 / 项目**
你经手过哪类合同 → 通常争议最大的条款是哪条 → 对方不让步你怎么办 → 最后怎么平衡的 → 业务方满意吗
分水岭：第 2 层（说不出争议条款，多半只是审过模板）

**链二：风险判断**
业务想做一件有法律风险的事，你怎么处理 → 如果领导支持业务呢 → 你会怎么留痕 → 如果风险落地了，责任怎么划
分水岭：第 2 层（一味说"不行"和轻易放行都失分）

**链三：专业深度**
（提到某个领域后）→ 这块最近的监管变化是什么 → 对你们业务有什么影响 → 你们做了什么调整
分水岭：第 2 层（说不出对业务的影响，停留在法条层）

## 专业性检验点

- 你主要处理哪类业务，合同量大概多少
- 争议解决走过诉讼还是仲裁，参与到什么程度
- 数据合规：个保法下的合规动作、跨境传输怎么处理
- 知识产权：商标布局、专利申请流程、侵权应对
- 合规：制度怎么落地的、培训怎么做的、有没有做过内部调查
- 律所转企业：为什么转，知不知道两边工作方式的差别
- 用一句业务听得懂的话解释你上次给的法律意见
- 讲一个你给了"可以做，但要这样做"的案例

## 按企业性质调整

- 大厂：业务节奏快，看能否在有限时间给可执行意见，新业务合规是热点
- 创业：一人法务部，问能不能同时管合同、劳动、融资、知产
- 国企银行：程序合规、审批留痕、国资监管、消费者权益保护、反洗钱
- 外企：总部合规政策与本地法律的冲突处理，英文合同能力
