# 运营出题手册（精简版）

> 涵盖：内容 / 用户 / 活动 / 社区 / 电商 / 短视频 / 私域运营

## 面试官在验什么

1. **这个数是不是你做上去的**：运营最容易借势（大促、平台给量、竞品出事），核心任务是剥掉外部因素。
2. **有没有闭环**：跑过完整闭环的人说得出复盘、说得出第二次怎么改。
3. **对用户的具体认知与执行密度**：能说出一类用户的真实行为，而不是画像模板；到底自己干了多少。

## 高频追问链

**链一：活动效果**
这个活动做得怎么样 → GMV 提升 30% 是和什么比的 → 同期大盘涨了多少 → 有没有做对照组 → 补贴投了多少，ROI 算过吗 → 不投补贴还有多少
分水岭：第 3 层（答不出对照或大盘，归因不成立）

**链二：用户增长**
拉新怎么做的 → 这批用户次留多少 → 七留呢，三十留呢 → 留下来的和自然新增有什么差别 → 获客成本多少 → 能不能规模化
分水岭：第 2 层（只说得出拉新量，说明只做了投放执行）

**链三：内容 / 短视频**
哪条爆了 → 为什么这条爆了 → 你复制成功了吗 → 后面几条数据怎么样 → 爆款率是多少
分水岭：第 3 层（一条爆款可能是运气，能不能复制才是能力）

## 专业性检验点

- 你负责的核心指标是什么，怎么定义的，周报看哪几个数
- 拉新、促活、留存、召回，你主要在哪一段
- 用什么工具看数据，有没有自己写过 SQL 或提过取数需求
- 一场活动从立项到上线要过哪些环节，你卡在哪个环节最多
- 私域：企微、社群、SOP、触达频次、掉粉率
- 电商：坑产、动销率、退货率、客单、履约
- 短视频：完播率、互动率、投流 ROI、自然流占比
- 说一类你负责过的用户的具体行为，不要用标签词

## 按企业性质调整

- 大厂：口径和归因追得最凶
- 创业：问预算受限时怎么做，重点看成本意识
- 国企银行：更看重活动合规性、审批流程、对外口径稳妥，数据要求反而低
- 外企：追问个人贡献（we/I），以及跨区域协作怎么推动
