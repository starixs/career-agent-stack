# 审计出题手册（精简版）

> 涵盖：四大 / 内资八大 / 企业内审

## 面试官在验什么

1. **职业怀疑和底线**：核心不是会不会做底稿，是被施压时守不守得住。
2. **抗压和项目节奏**：旺季强度是真实筛选项，验证你知不知道自己在选什么。
3. **具体做过哪些程序与沟通能力**：说得出细节的和只跟过项目的差别很大；向客户要资料、向经理汇报异常都不容易。

## 高频追问链

**链一：项目经历**
你在这个项目做了哪些科目 → 具体执行了哪些程序 → 函证回来不一致怎么处理的 → 你上报了吗 → 经理怎么决定的
分水岭：第 2 层（说做过某科目但讲不出程序，现场极易戳破）

**链二：职业判断（底线题）**
发现客户数据有问题但对方不配合，你怎么办 → 如果经理让你先过呢 → 如果影响项目进度呢 → 你会怎么记录
分水岭：第 2 层（中途松口即为重度失分，方向比技巧重要）

**链三：抗压**
旺季最忙的时候什么状态 → 怎么安排的 → 和客户起过冲突吗 → 怎么解决的
分水岭：第 3 层（没和客户要过资料的人没有冲突可讲）

## 专业性检验点

- 存货监盘你实际做过吗，流程是什么
- 函证的种类和不符时的替代程序
- 收入的截止性测试怎么做
- 重要性水平怎么确定的，谁定的
- 底稿复核有几级，你被 review 出最多的问题是什么
- 内审：风险评估怎么做的，整改跟踪机制是什么
- 为什么选审计，知道旺季强度吗
- 团队作业里你个人负责的部分，边界在哪

## 按企业性质调整

- 四大 / 外企：英文面常见，行为面试按 STAR 拆得很细
- 内资所 / 创业：更关注项目实操密度和出差意愿
- 国企内审 / 银行：合规导向，程序规范优先于效率
- 企业内审：独立性、和被审部门的关系、整改推动力是核心
