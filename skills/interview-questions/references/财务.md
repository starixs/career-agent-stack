# 财务出题手册（精简版）

> 涵盖：会计 / 出纳 / 财务分析 / 财务 BP / 税务 / FP&A

## 面试官在验什么

1. **准确性和底线**：第一筛子是会不会出错、会不会被业务带着走。
2. **记账还是能支持决策**：核算型和 BP 型的分界，面试官会主动区分。
3. **准则与税务的实际掌握**：答案有标准，最容易问出真假；BP 岗再看能否把财务语言翻译成业务听得懂的话。

## 高频追问链

**链一：核算**
月结几天完成 → 卡在哪个环节 → 遇到过账实不符吗 → 怎么查的 → 最后怎么处理的，有没有调账
分水岭：第 3 层（没查过账实不符，多半没独立做过月结）

**链二：财务分析 / BP**
你做的分析业务用了吗 → 举个具体的例子 → 你的建议让业务改了什么决定 → 省了多少钱或多赚了多少 → 怎么算的
分水岭：第 3 层（核算和 BP 的真正分界线）

**链三：准则 / 税务**
收入确认时点怎么判断的 → 这个业务模式为什么这样确认 → 如果换成另一种合同条款呢 → 税务上有什么差异
分水岭：第 2 层（说不出"为什么"，说明是按模板做账）

## 专业性检验点

- 新收入准则下你们业务怎么确认收入的
- 应收账款账龄怎么管的，坏账准备怎么计提
- 增值税进项转出的常见情形
- 预算怎么编的，实际和预算差异大的时候怎么分析
- 用什么系统，SAP / 用友 / 金蝶哪个模块，报表从哪里出
- FP&A：滚动预测的频率、驱动因素模型怎么搭
- 业务要求"变通"一下处理时，你怎么回应（底线题）
- 你报的数字单位和口径，精确到什么程度

## 按企业性质调整

- 大厂：BP 属性强，追问怎么支持业务、怎么算清一条业务线的账
- 创业：一人多岗，问能不能同时管账、税、报销、甚至融资材料
- 国企银行：预算管理、内控制度、审计整改、监管报送、合规口径，稳妥比敏捷重要
- 外企：US GAAP / IFRS 差异、总部报送、英文沟通
