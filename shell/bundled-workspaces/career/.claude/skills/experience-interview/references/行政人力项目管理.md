# 行政、人力与项目管理类经历访谈手册

适用：行政 / 助理 / 文秘；HR（招聘 / 培训 / 薪酬 / 员工关系 / HRBP）；项目管理 / PMO / 运营支持；学生干部与活动组织类经历。

## 证据载体

| 载体 | 强度 | 说明 |
|---|---|---|
| 项目排期表、甘特图、里程碑记录 | 强 | 证明管理过进度 |
| 招聘数据：岗位数、简历量、到面率、offer 接受率 | 强 | HR 招聘核心 |
| 会议纪要、周报 / 月报原件 | 中 | 证明协调与跟进 |
| 制度 / 流程文档（署名或版本记录） | 中 | 证明体系建设 |
| 活动方案、预算表、结算单 | 中 | 证明组织规模 |
| 培训课件、签到与反馈表 | 中 | 培训岗证据 |
| 供应商合同、采购比价记录 | 中 | 行政采购证据 |
| 员工满意度 / 离职率数据 | 中 | 需说明口径 |
| 学生组织任命文件、活动照片 | 弱 | 需补规模与个人角色 |
| 口头"我协调了很多部门" | 弱 | 标 pending |

## 评价指标

1. 项目规模：人数、周期、预算、涉及部门数
2. 进度：按时交付率、延期次数与原因
3. 招聘：平均关闭周期、渠道转化率、简历初筛通过率、offer 接受率
4. 编制与流动：负责编制人数、离职率、人效
5. 培训：场次、人次、满意度、覆盖率
6. 活动：场次、参与人数、预算、满意度
7. 成本：采购节省金额、费用控制幅度
8. 流程：建立或优化的流程数、处理时效变化
9. 风险处置：解决的冲突 / 纠纷 / 突发事件数量与结果
10. 文档产出：制度、报告、纪要数量

## 术语

- 甘特图：进度可视化图
- 里程碑：关键节点
- 排期：时间计划
- WBS：工作分解结构
- 风险登记：风险跟踪表
- 复盘：项目回顾
- 跨部门协调：多团队协作
- 升级：上报更高层处理
- JD：岗位描述
- 到面率：邀约后到场比例
- offer 接受率：录用接受比例
- 招聘漏斗：各环节转化
- HRBP：业务伙伴 HR
- 绩效：工作评价体系
- 薪酬带宽：薪资区间
- 离职率：流失比例
- 员工关系：劳动关系处理
- 三方协议：校招就业协议
- 用工形式：正编 / 外包 / 实习
- 考勤：出勤管理
- 固定资产：设备台账
- 比价：供应商报价对比
- 报销流程：费用审批
- OKR / KPI：目标管理方式

## 追问清单

**业务背景**
1. 你支持的业务 / 组织做什么？多少人、几个部门？
2. 你的职责范围是什么：主导、协调，还是执行？

**规模数据**
3. 项目或活动的人数、周期、预算各是多少？
4. 招聘了多少岗位、看了多少简历、到面多少、发了多少 offer？

**个人贡献**
5. 排期、协调、文档、现场，哪些是你独立负责的？
6. 和上级分工怎么划？你能拍板的范围是什么？

**成果**
7. 项目按时交付了吗？延期的话延了多久、原因是什么？
8. 有没有可量化的改善：周期缩短、成本降低、满意度提升？

**困难与解决**
9. 两个部门意见不一致时你怎么推的？拉了什么会、找了谁？
10. 突发状况（场地取消、人员临时变动）怎么处理的？

**关键判断**
11. 有没有你自己提出并落地的流程或制度？之前是什么样？
12. 资源不够时你砍了什么、保了什么？

**降级问法**
- 「没做过项目管理」→ 社团、班级、比赛团队里有没有你排进度、催交付、协调几个人的经历？多少人、多久？
- 「没做过人事工作」→ 社团招新面试过多少人？组织过培训或迎新吗？

> 本手册为通用归纳，具体口径以用户实际工作为准
