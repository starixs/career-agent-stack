# 战略 / 咨询岗复盘手册（精简版）

> 涵盖：MBB / Big 4 Strategy / 大厂战略部 / 投资战略 / 行业研究

## 面试官在验什么

1. **结构化思维。**case 面试考拆解方式，不是标准答案。
2. **假设是否合理。**信息不全时能不能给站得住的假设并说明依据。
3. **数字感。**估算题里量级错了比算错更严重。
4. **能不能被引导。**面试官给提示时接不接得住，是协作能力的直接体现。

## Case 复盘的锚点：面试官在哪里打断

| 打断位置 | 一种可能的解释 | 对应标签 |
|---|---|---|
| 刚开始就打断 | 没澄清题目边界直接开做 | `content:case-structure` |
| 列框架时打断 | 框架有明显缺口，或套用现成模型 | `content:case-structure` |
| 某个假设处打断 | 假设不成立且没说明依据 | `content:case-assumption` |
| 算数时打断 | 数量级偏差 | `content:metric-definition` |
| 快结束时打断 | 时间超了或没给结论 | `delivery:excessive-length` |

打断也可能只是时间不够。注意区分 `probe:guide`：面试官主动给提示通常是希望你答好，不计丢分。

## 高频追问链

**链一：case 推进**
（给出题目）→ 你先澄清了什么 → 框架怎么想出来的 → 这一支为什么重要 → 数据支持你的判断吗 → 所以建议是什么
（分水岭在第三层：说不出为什么重要，说明框架是套的）

**链二：PEI / 个人经历面**
讲一次你影响他人的经历 → 对方一开始为什么不同意 → 你具体说了什么 → 结果怎么样 → 现在回头看还能怎么做
（MBB 的 PEI 追问密度极高，一个故事能追十几层；分水岭在第三层）

## 特有丢分点

| 表现 | 标签 | 说明 |
|---|---|---|
| 硬套 4P、SWOT、波特五力 | `content:case-structure` | 模板化是该岗位最重的失分 |
| 不出声地想 | `delivery:no-structure` | 面试官看不到思路无法评分 |
| 估算时量级错误 | `content:metric-definition` | 比算错更严重 |
| 最后不给明确建议 | `content:decision-rationale` | case 必须收口 |
| PEI 故事笼统，追到第三层就没细节 | `content:factual-gap` | |

## 与企业性质叠加

- **MBB / 外企咨询**：case + PEI 双线，PEI 追问深度是最大差异点，英文面常见
- **Big 4 Strategy**：case 稍缓，更看重行业理解和落地可行性
- **大厂战略部**：更关注业务理解和内部推动能力，纯 case 比例低
- **投资 / 行研 / 国企研究部门**：追行业判断的依据、数据来源、与市场共识的差异；国企更看政策口径和稳妥
