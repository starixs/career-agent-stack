# HR 岗复盘手册（精简版）

> 涵盖：HRBP / 招聘 / 培训 / 薪酬绩效 / 员工关系 / OD

## 面试官在验什么

1. **执行 HR 还是懂业务的 HR。**这条线区分了绝大多数候选人。
2. **处理人的事的分寸。**员工关系、裁员、绩效沟通里有没有边界感。
3. **数据意识。**招聘周期、离职率、人效答不上，说明没被量化管理过。
4. **面 HR 的人通常也是 HR。**同行对话术极其敏感，套话会被立刻识别。

## 高频追问链

**链一：招聘**
负责的岗位平均多久关闭 → 最难招的是哪个、为什么 → 你做了什么让它变快 → 渠道转化率各多少 → 用人经理和你意见不一致时怎么办
（分水岭在第三层）

**链二：HRBP**
你支持的业务线是做什么的 → 他们今年最大的挑战是什么 → 你为这个挑战做了什么 → 效果怎么衡量
（分水岭在第二层：说不出业务在干什么的 BP，通常被判定为事务型）

**链三：员工关系**
处理过劳动纠纷吗 → 具体什么情况 → 你怎么谈的 → 最后怎么了结 → 事后有没有改流程

## 特有丢分点

| 表现 | 标签 | 说明 |

## 专业性检验点

- 负责的编制多少人，流动率多少
- 招聘：初筛通过率、面试通过率、offer 接受率
- 薪酬：宽带薪酬怎么设计，调薪包怎么分配
- 绩效：用什么工具，强制分布与否，争议怎么处理
- 劳动法：三期女员工、竞业限制、n+1 适用条件
- OD：做过什么组织诊断，用了什么模型，落地了什么

## 与企业性质叠加

- **大厂**：数据化管理，人效、编制、组织效能是高频词
- **创业公司**：从零搭体系，问能不能一个人把招聘薪酬社保全包
- **国企 / 银行**：编制管理、职级体系、政策执行、合规用工、总分行协同
- **外企**：全球政策本地化、总部与本地平衡，英文面常见
