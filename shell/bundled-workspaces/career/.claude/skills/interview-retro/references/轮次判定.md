# 轮次判定

> 这一轮为什么问这些、该问到多深，由轮次和面试官身份决定；公司性质决定的是同样的回答会被怎么解读。同一句"你期望薪资多少"，HR 一面问通常和预算筛选有关，用人经理二面问可能在核算成本，终面问更可能和推进相关。这些都是常见情况，不是规律。
>
> 先用本文件定位这一轮的考察重心，再用企业性质手册解读具体信号。

## 一、按轮次

### HR 面（可能在最前也可能在最后）

**在验什么：**基本情况筛查——离职原因是否说得通、稳定性、薪资期望是否在预算内、动机是否合理、有没有明显风险点。HR 通常不评估专业能力，评估的是风险。

**丢分点：**离职原因和简历时间线对不上，或和其他轮次说法不一致（HR 会交叉核对）；抱怨前公司、前领导；薪资期望没有依据、被追问时随口改口；对公司业务一无所知。

**复盘要点：**诊断重心是**一致性**，不是深度。对照用户在其他轮次的说法检查前后矛盾。只面了 HR 一轮时，重点检查离职原因的逻辑闭环。

**位置差异：**HR 面在最前通常是筛选，在最后通常和流程、薪资沟通有关。最后一轮 HR 面问得细，一种可能是流程在推进，也可能只是该公司入职前信息采集较完整。

### 一面（同级或直属上级）

**在验什么：**硬能力和真实性。任务是把注水简历筛掉，节奏快，覆盖面广，单点不钻太深。

**丢分点：**数据口径答不出、项目细节含糊、基础专业问题答错。

**复盘要点：**一面被追问的点在后续轮次再次出现的情况比较常见，值得重点提取；但要看追问性质，流程型追问的预测价值低。

### 二面（部门负责人 / 用人经理）

**在验什么：**权重通常较高。用人经理判断的是要不要这个人进团队，常锁定一两个核心项目深入追问，并开始考察取舍判断（资源只够做一件事砍哪个）。

**丢分点：**归因说不清、决策讲不出备选方案、反事实问题接不住、对成本或协作迟钝。

**复盘要点：**诊断要做得最细。但**这一轮的表现和最终进展之间没有稳定的对应关系**：表现顺畅但流程停住很常见，原因可能在招聘名额、薪资区间、内部候选人等面试之外；被追问到卡壳也不必然导致流程终止。报告里只描述材料显示的情况，**不反推流程结果**。

### 三面 / 终面（总监 / GM / 跨部门）

**在验什么：**项目细节退居次要，考判断力、行业认知、动机自洽性和文化匹配。追问"为什么"多于"是什么"。

**丢分点：**行业观点经不起反驳（可能准备不深，也可能当场没反应过来）；职业规划和岗位对不上；动机和过往轨迹矛盾。

**复盘要点：**终面的丢分往往是**认知层面**的，短期补不上。要诚实告诉用户，不给"回去多准备"这种没用的建议。

### 交叉面 / 同级面（外企常见，大厂偶尔）

**在验什么：**协作手感、好不好共事。维度更软，但一票否决权真实存在。

**丢分点：**表现出优越感；对同级的问题敷衍；只对着"能决定我去留的人"用力。

## 二、按校招 / 社招 / 实习

| | 考察重心 | 对数字的容忍度 | 最重的丢分 |
|---|---|---|---|
| **校招** | 项目真实性、思考潜力、学习能力 | 高，没人指望学生有漂亮数据 | 项目是自己做的还是抄的、想清楚没有 |
| **社招** | ownership、归因、不可替代性 | 低，数字要经得起问 | 把团队成果说成个人成果 |
| **实习** | 基础能力、能不能干活、时间投入 | 最高 | 出勤时间说不清、明显只是刷经历 |

**校招特有：**"你怎么理解这个岗位"检验有没有做基本功课，答不好会被判定为不重视。

**社招特有：**空窗期、跳槽频率、职级和薪资匹配度会被交叉验证。前后不一致比答得不好更严重。

## 三、按面试官身份反推

用户不确定对方身份时，从问的问题反推：

| 他反复问 | 他可能是 |
|---|---|
| 离职原因、薪资、到岗时间、稳定性 | HR |
| 项目细节、数据口径、技术方案 | 同级或一线主管 |
| 取舍判断、资源分配、团队协作 | 用人经理 |
| 行业判断、长期规划、对公司战略的理解 | 总监及以上 |
| 你怎么和别的团队打交道 | 交叉面 / 同级面 |

反推有参考价值：用户以为在面用人经理、但对方问的多是 HR 类问题，说明这一轮的定位可能和准备方向不一致。但部分公司的用人经理也会代问 HR 类问题，不能仅凭问题类型确定身份。
