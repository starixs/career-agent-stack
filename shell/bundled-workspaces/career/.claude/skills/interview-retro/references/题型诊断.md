# 题型诊断

> 逐题标注时用本文件。每一题先归类，再看"面试官在问什么"，最后对照常见失分模式定位问题。
>
> 这是通用层；岗位专用的追问链和检验点在各岗位手册里，两者一起用。
>
> **本文件不提供任何示范答案。**这里写的是诊断标准，不是答题模板。重答只能用用户亲口说过的事实组装。

## 分类体系

| 题型 | 典型问题 |
|---|---|
| 开场类 | 自我介绍、路上顺利吗 |
| 动机类 | 为什么投这个岗位、为什么选我们、职业规划 |
| 履历类 | 离职原因、空窗期、跳槽频率、职级变化 |
| 项目深挖类 | 讲一个最有成就感的项目、这个数据怎么来的 |
| 行为类 | 讲一次冲突 / 失败 / 压力 / 说服他人的经历 |
| 业务认知类 | 你怎么看我们的产品、竞品怎么样、行业趋势 |
| Case / 半结构化 | 假设你要提升 XX 指标，你怎么做 |
| 自我认知类 | 优点缺点、上级会怎么评价你 |
| 反问类 | 你还有什么想问的 |

## 一、开场类

**在问什么：**表达能力的第一印象、结构感、有没有准备。自我介绍是少数可以完全提前准备的题，答得松散容易被理解为准备不足。

**常见失分：**复述简历（面试官手里就有）；超过两分钟还没说到和岗位相关的部分；没有落点，说完就停。

**诊断要点：**检查时长和结构。面试官中途打断记为 `signal:interrupted`，一种可能是内容偏离或过长，也可能是面试官已读过简历想直接进重点或当天时间紧，报告里要给其他解释。

## 二、动机类

**在问什么：**海投还是真的想来，对公司的了解是不是只看了官网首页。

**常见失分：**理由可以套在任何一家公司上；只讲想得到什么，没讲能带来什么；动机和过往轨迹矛盾。

**诊断要点：**把回答里的公司名替换成竞品，句子依然成立，说明缺少针对性。

## 三、履历类

**在问什么：**一致性和风险。离职原因是最容易被交叉核对的一题，HR 问一遍，用人经理通常再问一遍。

**常见失分：**评价前公司、前领导时带负面情绪；理由和时间线对不上；空窗期支支吾吾或临时编理由。

**诊断要点：**用户在多轮面试中都被问到离职原因时，把各轮说法拉出来横向比对，这是跨场归档的独特价值。

## 四、项目深挖类

**在问什么：**这件事是不是你做的、你做的是哪部分、想清楚了没有。

**分层诊断，看用户在第几层卡住：**

| 层级 | 面试官问什么 | 卡在这一层通常反映 |
|---|---|---|
| 第一层 | 讲讲这个项目 | 讲不清楚 = 表达问题 |
| 第二层 | 这个数据怎么算的 | 答不出口径 = 数字可能是听来的 |
| 第三层 | 怎么证明是你的功劳 | 答不出归因 = 可能是团队成果 |
| 第四层 | 当时还有什么备选方案、为什么没选 | 答不出 = 执行者不是决策者 |
| 第五层 | 如果重来一次改哪里 | 答不出 = 没复盘过 |

**诊断要点：**明确写出用户在第几层卡住。层级数字比任何形容词都有信息量，也是跨场分析里最有价值的记录项。

## 五、行为类

**在问什么：**回答的颗粒度。真经历过的人说得出具体细节，没经历过的通常只有形容词。

**常见失分：**Situation 讲太长、Action 太薄（理想配比 Action 占一半以上）；通篇"我们"；失败题给假失败（太追求完美）；冲突题里自己永远是对的一方。

**诊断要点：**统计回答里具体名词和数字的密度。全是形容词和抽象动词的回答，无论多顺都是失分的。

## 六、业务认知类

**在问什么：**做没做功课、有没有独立判断。

**常见失分：**只夸不评；观点从公开报道搬来，追问一层就没了；提了批评但不给建设性方向。

**诊断要点：**面试官对用户观点提出反方意见时，看接住了没有。接不住意味着观点可能是临时背的，要明确写进报告。

## 七、Case / 半结构化

**在问什么：**思维结构、假设是否合理、能不能被引导。

**诊断的关键动作：看面试官在哪里打断。**打断位置通常指向问题所在，但也可能只是时间不够：

| 打断位置 | 一种可能的解释 |
|---|---|
| 刚开始就打断 | 没澄清题目边界直接开做 |
| 列框架时打断 | 框架漏了一整块，或太模板化 |
| 某个假设处打断 | 假设不成立，且没说明依据 |
| 算数时打断 | 数字量级错了 |
| 快结束时打断 | 时间超了，或没给出结论 |

**常见失分：**不澄清直接答；框架照搬（4P、SWOT 硬套）；不出声地想；最后不给明确结论。

## 八、自我认知类

**在问什么：**自知之明和责任承担。

**常见失分：**缺点选了伪缺点，或选了岗位核心能力（应聘财务说自己粗心）；"上级怎么评价你"答成自我表扬没有事例；讲缺点不讲改进动作。

**诊断要点：**看缺点是否有具体改进动作和效果。

## 九、反问类

**在问什么：**有没有认真考虑过这个机会、思考深度。外企和大厂都把这一环作为正式评估项。

**常见失分：**说"没有问题了"；问网上能查到的信息；问题与面试官身份错配（问 HR 技术栈、问技术负责人福利）；国企场景特有：问薪资、加班、晋升速度，可能被读作动机不纯。

**诊断要点：**记录反问环节时长。面试官在这里多花时间，可能和争取候选人有关，也可能只是当天时间宽裕。
