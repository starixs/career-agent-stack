# 审计岗复盘手册（精简版）

> 涵盖：四大 / 内资八大 / 企业内审

## 面试官在验什么

1. **职业怀疑和底线。**核心不是会不会做底稿，是被施压时守不守得住。
2. **抗压和项目节奏。**旺季强度是真实筛选项，面试官验证你知不知道自己在选什么。
3. **具体做过哪些程序。**说得出细节的和只跟过项目的差别很大。
4. **沟通能力。**向客户要资料、向经理汇报异常，两件事都不容易。

## 高频追问链

**链一：项目经历**
你在这个项目做了哪些科目 → 具体执行了哪些程序 → 函证回来不一致怎么处理 → 你上报了吗 → 经理怎么决定的
（分水岭在第二层）

**链二：职业判断（底线题）**
发现客户数据有问题但不配合，怎么办 → 如果经理让你先过呢 → 如果影响项目进度呢 → 你会怎么记录
（答案方向比技巧重要，中途松口即重度失分）

**链三：抗压**
旺季最忙时什么状态 → 怎么安排的 → 和客户起过冲突吗 → 怎么解决

## 特有丢分点

| 表现 | 标签 | 说明 |
|---|---|---|
| 底线题里出现"先按经理说的做" | `content:self-awareness` | 重度失分 |
| 说做过某科目但讲不出具体审计程序 | `content:factual-gap` | 极易被戳破 |
| 对加班强度明显意外或抗拒 | `content:role-motivation` | 说明没做功课 |
| 只说"配合完成"，个人部分不清晰 | `content:personal-contribution` | 团队作业，这一问必来 |
| 说不清为什么选审计 | `content:role-motivation` | 流动率高，权重大 |

## 专业性检验点

- 存货监盘实际做过吗，流程是什么
- 函证的种类和不符时的替代程序
- 收入的截止性测试怎么做
- 重要性水平怎么确定、谁定的
- 底稿复核有几级，被 review 出最多的问题是什么
- 内审：风险评估怎么做，整改跟踪机制

## 与企业性质叠加

- **四大 / 外企**：英文面常见，`language:` 类标签单独记；行为面试按 STAR 拆得很细
- **内资所 / 创业期事务所**：更关注实操密度和出差意愿
- **企业内审（含国企）**：独立性、和被审部门的关系、整改推动力；国企内审程序规范优先于效率
- **大厂内审**：业务理解和数据化审计工具是加分项
