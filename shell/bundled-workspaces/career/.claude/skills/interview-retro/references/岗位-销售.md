# 销售岗复盘手册（精简版）

> 涵盖：B 端销售 / KA / BD / Account Manager / 客户成功

## 面试官在验什么

1. **数字是最直接的筛子。**完成率、回款、客单，含糊就等于没做好。
2. **靠资源还是靠方法。**只靠老客户和人脉的销售换个赛道就归零，面试官会专门测。
3. **拿单的具体过程。**真拿过大单的人说得出决策链、卡在哪、怎么破。
4. **抗压和稳定性。**销售流动率高，面试官会验证离职原因和业绩的关系。

## 高频追问链

**链一：业绩**
去年完成率多少 → 团队平均多少、你排第几 → 最大的一单多少 → 怎么谈下来的 → 这个客户是公司给的线索还是你自己开的
（分水岭在最后一层：`content:attribution` 常在这里成立）

**链二：拿单过程**
这个客户的决策链是谁 → 谁拍板、谁会反对 → 怎么接触到拍板的人 → 中间卡在哪 → 最后靠什么破局
（说不出决策链通常没做过真正的 B 端大单；分水岭在第一层）

**链三：丢单**
丢过印象最深的单是哪个 → 为什么丢 → 现在回头看该怎么做 → 后来有没有再拿回来

## 特有丢分点

| 表现 | 标签 | 说明 |
|---|---|---|
| 说不出准确的完成率和团队排名 | `content:factual-gap` | 销售岗最致命 |
| 业绩主要来自公司分配的存量客户 | `content:attribution` | 会被一路追问 |
| 讲不清客户的决策链 | `content:domain-depth` | B 端销售核心检验 |
| 丢单原因全归给价格或产品 | `content:self-awareness` | 说明不复盘 |
| 离职原因和业绩表现对不上 | `content:career-consistency` | 面试官会交叉核对 |

## 专业性检验点

- 年度指标多少，怎么拆到季度和月度
- 客单价、成交周期、赢单率各是多少
- 用什么 CRM，商机阶段怎么划分
- 回款情况，有没有坏账
- 客户成功：续费率、NDR、健康度怎么定义
- 渠道：怎么招商、怎么管、返点政策

## 与企业性质叠加

- **大厂**：数据化管理，商机阶段和转化率追得细
- **创业公司**：从零开客户，问没有品牌背书时怎么打开局面
- **国企 / 银行**：关系维护和合规并重，对灰色操作零容忍
- **外企**：forecast 准确度、pipeline management、英文汇报是高频考点
