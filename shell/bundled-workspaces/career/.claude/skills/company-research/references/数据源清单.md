# 数据源清单

原则：公开网页能检索的走 Web Search；需验证码或登录的渠道，只在报告里给人工核验入口，不假装已查过。人工入口永远写进「需人工核实」清单。

## 中国大陆（主战场）

| 数据源 | 用途 | 接入方式 |
|---|---|---|
| 百度搜索 | 综合线索：新闻、欠薪、仲裁、裁员、招聘动态 | 可自动检索（Web Search），主引擎 |
| 必应搜索 | 补充线索；中文公司名易被拆字，命中率低 | 可自动检索（Web Search），辅助 |
| 爱企查 aiqicha.baidu.com | 工商基础：法定代表人、注册资本、成立时间、经营状态 | 搜索摘要可检索；详情页需验证码，只给人工入口 |
| 天眼查 / 企查查 | 工商变更记录、司法案件汇总、关联方 | 只给人工入口（付费或登录） |
| 国家企业信用信息公示系统 gsxt.gov.cn | 经营异常名录、严重违法、行政处罚、年报 | 只给人工入口（验证码 + 登录），红线 2 主渠道 |
| 中国执行信息公开网 zxgk.court.gov.cn | 被执行人、失信被执行人、限制消费 | 只给人工入口（验证码），红线 1 主渠道 |
| 信用中国 creditchina.gov.cn | 行政处罚、失信惩戒、欠税 | 部分公开可检索，细节给人工入口 |
| 裁判文书网 wenshu.court.gov.cn | 判决书（劳动争议、合同纠纷） | 只给人工入口（登录 + 验证码），红线 4 / 6 主渠道 |
| 中国庭审公开网 | 开庭公告 | 可检索，红线 6 辅助 |
| 各地人社局官网 | 重大劳动保障违法、欠薪黑名单公告 | 可自动检索（Web Search 搜「人社局 + 公司名 + 欠薪」），红线 3 / 7 主渠道 |
| 看准网 / 职友集 | 员工评价、薪资爆料 | 只给人工入口（反爬强），不抓原文 |
| 脉脉 / 知乎 / 小红书 | 员工真实评价、裁员降薪讨论 | 只给人工入口；搜索摘要可作线索 |
| BOSS 直聘等招聘平台 | 在招岗位数量、招聘主体名称、公司评价 | 只给人工入口；用于主体消歧 |

## 使用规则

1. 搜索摘要只是线索，命中的每条证据都要标「需打开原文核实」。
2. 招聘平台显示的品牌名不等于工商全称，先消歧再查。
3. 员工评价只给入口链接，不自动抓取原文，不采集个人信息。
4. 证据权重：官方公告 > 正规新闻媒体 > 论坛问答 > 招聘平台。
5. 搜不到不代表没风险，报告里必须写「公开网页无记录，不代表无风险」。

## 境外公司快速人工核验模板

1. 搜 `公司名 + lawsuit / sued / judgment`，看诉讼记录。
2. 搜 `公司名 + wage theft / unpaid wages`，看欠薪记录。
3. 搜 `公司名 + layoff / redundancy`，看裁员动态。
4. 在 OpenCorporates 或当地注册处（英国 Companies House、香港公司注册处、新加坡 ACRA）查注册主体与状态，区分品牌与法律实体。
5. 员工评价：Glassdoor / Indeed / Blind（英文），看准 / 脉脉（中文外企评价）。
