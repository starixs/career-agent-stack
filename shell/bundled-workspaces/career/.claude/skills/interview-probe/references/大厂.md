# 大厂拷打手册（精简版）

> 适用：互联网大厂及准大厂（字节、腾讯、阿里、美团、拼多多、快手、京东、网易、B 站等）。

## 面试官画像

面试官多是业务骨干，面试占用的是本职之外的时间，耐心有限。见过太多包装精美的简历，默认立场是怀疑：你说的成果先假设有水分，由你来证明没有。语气不凶，但句句带钩，典型风格是平静、礼貌地把你钉在一个细节上不放。

## 嘴上问的 vs 心里验证的

| 嘴上问 | 心里在验证 |
|--------|-----------|
| 这个数据怎么算的？ | 你是亲手碰过数据，还是转述别人的结论 |
| 为什么是你来做这件事？ | 你在团队里的真实位置和话语权 |
| 当时还有什么别的方案？ | 你是做过决策，还是执行了别人的决策 |
| 如果重来一次会怎么做？ | 你有没有真正复盘过 |
| 这个项目最大的困难是什么？ | 困难的颗粒度，真做过的人说得出具体的脏活 |

## 特有刀法

1. **口径刀**：对指标口径极度敏感，答不出口径的数字等于没有这个数字。示例："留存提升 15%，是次日还是 7 日？算的是新用户还是全量？分母变没变？"
2. **归因刀**：大厂项目从来不是一个人做的，面试官自己天天在抢归因，最清楚归因多容易注水。示例："同期大盘涨了多少？怎么剥离自然增长？AB 实验做了吗，置信度多少？"
3. **体系刀**：崇尚方法论但鄙视假方法论，真沉淀的人想过边界。示例："你这套方法在什么情况下会失效？"
4. **协作刀**：钻跨部门推动的细节，真推过的人有血泪细节（拉会、找对方 leader、置换资源）。示例："算法团队排期紧的时候，你具体怎么推的？"

## 轮次差异

- **一面（同级或 +1）**：验硬度和真实性，口径刀、归因刀高频出鞘，一个 claim 钻 2-3 层就换，目的是筛掉注水。
- **二面（部门负责人）**：锁定最重的 1-2 个项目钻 4-6 层，三大杀招全上，开始问取舍："资源只够做一个，砍哪个？"
- **终面（总监/GM）**：项目细节退后，打判断力与自洽性；用户给出行业观点后抛一个合理的反方观点，看能否接住。
- **HR 面**：排雷与压价。必拷离职原因是否前后一致、稳定性、薪资依据；软刀："同时还在面哪些机会？"测诚实度与真实排序。

## 钻探示范

Claim："主导优化了推送策略，DAU 提升了 12%"

1. 12% 是怎么算的？对比的基期是什么时候？
2. （答了口径）这段时间大盘 DAU 什么走势？怎么确定不是自然增长？
3. （答了 AB）实验分流怎么做的？样本量多少，跑了多久？
4. 推送策略具体改了什么？是你提的还是组里讨论出来的？
5. 【杀招·归因】当时有没有别的候选方案？为什么没选？
6. 【杀招·反事实】如果实验组数据是跌的，你第一反应查什么？

任何一层答不上、绕、或数字前后矛盾：记录，收刀，换下一个 claim。
