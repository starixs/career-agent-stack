# 国企央企拷打手册（精简版）

> 适用：国企、央企、事业单位、银行总行/分行、运营商等体制内或半体制内单位。

## 面试官画像

国企面试常为多人面试组（业务领导 + 人事 + 纪检或工会代表），形式正式、气氛克制。问题表面温和宽泛，但每道题背后都有一个不会明说的考察点，而且非常看重表达的分寸感：说得太满、太个人英雄主义、太"互联网黑话"都会减分。追问不如大厂凶，但对"答非所问"和"价值观不对齐"的容忍度极低。

## 嘴上问的 vs 心里验证的

| 嘴上问 | 心里在验证 |
|--------|-----------|
| 谈谈你对我们单位的了解 | 是不是海投的，对体制内工作的认知是否现实 |
| 你在团队中一般扮演什么角色？ | 集体意识，会不会抢功、是否服从安排 |
| 互联网节奏快，我们流程多，你怎么适应？ | 稳定性，是把这里当跳板还是养老 |
| 讲一个你和领导意见不一致的经历 | 分寸感：既要有想法，又要懂得怎么提 |
| 你的职业规划是什么？ | 打不打算长干，预期和单位能给的是否匹配 |

## 特有刀法

1. **稳定性刀**：所有问题最终通向"你会不会待得住"，追问要具体到场景。示例："一个审批要走两周，业务窗口要错过了，你怎么办？"听是抱怨流程还是理解流程存在的原因。
2. **集体刀**：候选人说"我主导/我决策"时，刀不在质疑真假，而在试探归功方式。示例："这个成果里，团队和领导的作用是什么？"全揽在自己身上是危险信号。**注意：这一刀与大厂归因刀方向相反，拷打时必须切换判定标准。**
3. **分寸刀**：标准坑题，看能否给出有层次的答案（场合、方式、底线）。示例："领导的决定你认为明显有问题，你会怎么做？"直接说"坚决执行"显得没脑子，说"据理力争"显得不懂规矩。
4. **认知刀**：不接受"稳定、有归属感"就翻篇。示例："你了解我们在推的改革/数字化转型吗？你的互联网经验在这里哪些有用、哪些会失效？"

## 轮次差异

- **初面（人事 + 业务）**：认知刀、稳定性刀为主，过滤海投和幻想型候选人。
- **领导面**：分寸刀、集体刀为主，多用情景题；语气平和但每个回答都在被打分。
- **终面 / 结构化环节**：常有固定题目限时作答，可穿插一道："请用三分钟讲一次你处理复杂协调工作的经历"，再针对最空的部分追问。
- **HR 面（人事面）**：接近"政审前哨"。重点拷长期意向（家在哪、对象工作在哪，这类问题在体制内语境常见，模拟时照问并在复盘里解释意图）、纪律意识（有没有副业）、薪资落差（"收入少三分之一，家里支持吗？"）。

## 钻探示范

Claim（互联网转国企候选人）："希望在更稳定的平台上长期发展"

1. 稳定具体指什么？如果指不裁员，你了解我们近两年的人员优化情况吗？
2. （答得笼统）你了解这个岗位日常具体做什么吗？描述一下你想象中入职后的一周。
3. （描述偏理想化）实际上大量时间在写材料、走流程、对接上级检查，和你想象的差距大吗？
4. 【杀招·反事实】入职半年发现晋升和业绩关系不大、更多看资历，你会怎么调整心态？
5. 【杀招·分寸】你之前习惯直接挑战方案，在这里开会发现方案有漏洞，当场说还是会后说？为什么？
6. 【杀招·集体】你刚才讲的那个项目成果，领导和同事分别起了什么作用？
