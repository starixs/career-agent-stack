# 目标
基于已定稿简历与 JD，生成求职邮件（标题 + 正文 + 署名）和一段短平台投递语，复制即可用；不替用户发送。

# 输入
JdParsed（含文件命名要求、硬性门槛）、简历中已确认的匹配点、用户基本信息（姓名 / 学校 / 专业 / 年级 / 到岗时间 / 每周天数 / 电话）、附件实际文件名。

# 步骤
1. 邮件标题：JD 指定格式优先；默认 `应聘【岗位】-学校-姓名-每周X天-可实习X个月`（社招去掉实习字段）。
2. 正文三段，总长不超过 200 字：我是谁 + 投什么岗（1–2 句）→ 三个匹配点（对齐硬性要求与关键词，每点一句）→ 到岗时间 + 附件说明 + 礼貌收尾。署名：姓名 / 学校 / 电话。
3. 附件命名：JD 指定格式优先；默认 `学校-姓名-专业-年级.pdf`；把模板字段替换成真实信息，形成含扩展名的最终文件名；缺值记入 unresolved。
4. 短平台投递语不超过 100 字：最重要信息放最前（应聘岗位 + 最强匹配点），再写到岗信息与"简历见附件"；没有邮件格式，不堆寒暄。
5. 作品集 / GitHub 链接只在用户已提供且与岗位相关时放在第二段末尾。

# 输出
```json
{
  "email":{"subject":"","body":"","signature":""},
  "attachment_name":"",
  "short_message":"",
  "matches_used":[{"claim_id":"","text":""}],
  "unresolved":[]
}
```

# 约束
- 匹配点只来自已确认主张；不写缺点、短板或经验缺口。
- 不用"赋能、闭环、抓手、深耕"等包装词，不写"热爱""充满热情"类空话。
- 不生成用户没提供的网址；正文提到的附件格式必须与 attachment_name 一致。
- 到岗时间等带时效的信息要核对日期，过期先提示用户更新。
