# HR 出题手册（精简版）

> 涵盖：HRBP / 招聘 / 培训 / 薪酬绩效 / 员工关系 / OD

## 面试官在验什么

1. **执行 HR 还是懂业务的 HR**：这条线区分了绝大多数候选人。
2. **处理人的事的分寸**：员工关系、裁员、绩效沟通场景里有没有边界感和中立感。
3. **数据意识**：招聘周期、离职率、人效答不上来，说明没被量化管理过；面 HR 的人通常也是 HR，对套话极敏感。

## 高频追问链

**链一：招聘**
你负责的岗位平均多久关闭 → 最难招的是哪个，为什么难 → 你做了什么让它变快 → 渠道转化率各是多少 → 用人经理和你意见不一致时怎么办
分水岭：第 4 层（答不出渠道转化率，说明没盯过漏斗）

**链二：HRBP**
你支持的业务线是做什么的 → 他们今年最大的挑战是什么 → 你为这个挑战做了什么 → 效果怎么衡量的
分水岭：第 2 层（说不出业务在干什么的 BP，通常是事务型）

**链三：员工关系**
处理过劳动纠纷吗 → 具体什么情况 → 你怎么谈的 → 最后怎么了结的 → 事后有没有改流程
分水岭：第 3 层（谈判过程讲不具体，多半只是跟过）

## 专业性检验点

- 你负责的编制多少人，人员流动率多少
- 招聘：简历初筛通过率、面试通过率、offer 接受率
- 薪酬：宽带薪酬怎么设计的、调薪包怎么分配的
- 绩效：用什么工具，强制分布还是不分布，争议怎么处理
- 劳动法：三期女员工、竞业限制、N+1 的适用条件
- OD：做过什么组织诊断，用了什么模型，落地了什么
- 讲一个你立场必须中立的场景，你当时怎么说的
- 你支持的业务今年的核心指标是什么

## 按企业性质调整

- 大厂：数据化管理，人效、编制、组织效能是高频词
- 创业：从零搭体系，问能不能一个人把招聘薪酬社保全包了
- 国企银行：编制管理、职级体系、政策执行、合规用工、条线协同
- 外企：全球政策本地化、总部与本地的平衡，英文面常见
