# 销售出题手册（精简版）

> 涵盖：B 端销售 / KA / BD / Account Manager / 客户成功

## 面试官在验什么

1. **数字是最直接的筛子**：完成率、回款、客单，含糊就等于没做好。
2. **靠资源还是靠方法**：只靠老客户和人脉的销售换个赛道就归零。
3. **拿单的具体过程与稳定性**：真拿过大单的人说得出决策链、卡点和破局；离职原因和业绩之间的关系会被交叉验证。

## 高频追问链

**链一：业绩**
去年完成率多少 → 团队平均多少，你排第几 → 最大的一单多少 → 怎么谈下来的 → 这个客户是公司给的线索还是你自己开的
分水岭：第 5 层（存量客户还是自开，归因在这里成立）

**链二：拿单过程**
这个客户的决策链是谁 → 谁拍板，谁会反对 → 你怎么接触到拍板的人的 → 中间卡在哪 → 最后靠什么破的局
分水岭：第 1 层（说不出决策链，通常没做过真正的 B 端大单）

**链三：丢单**
丢过印象最深的单是哪个 → 为什么丢的 → 现在回头看当时该怎么做 → 后来有没有再拿回来
分水岭：第 2 层（全部归给价格或产品，说明不复盘）

## 专业性检验点

- 你的年度指标多少，怎么拆到季度和月度的
- 客单价、成交周期、赢单率各是多少
- 用什么 CRM，商机阶段怎么划分的
- 回款情况怎么样，有没有坏账
- 客户成功：续费率、NDR、健康度怎么定义的
- 渠道：怎么招商的、怎么管的、返点政策
- 业绩里自开客户和分配客户各占多少
- 离职时手上的客户和业绩完成情况

## 按企业性质调整

- 大厂：数据化管理，商机阶段和转化率追得细
- 创业：从零开客户，问没有品牌背书时怎么打开局面
- 国企银行：关系维护和合规并重，对灰色操作零容忍
- 外企：forecast 准确度、pipeline management、英文汇报是高频考点
