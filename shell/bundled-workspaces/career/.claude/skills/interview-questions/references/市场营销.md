# 市场营销出题手册（精简版）

> 涵盖：品牌 / 数字营销 / 内容营销 / 公关 / 活动 / KOL 投放

## 面试官在验什么

1. **花钱的效率**：市场是花钱部门，第一关心预算用得值不值。
2. **品效之间的取舍**：只会讲曝光和声量的，容易被判定为不懂生意。
3. **资源掌控与判断的具体性**：能不能压价、协调、兜住事故；说不出为什么这个 campaign 好，说明在执行别人的判断。

## 高频追问链

**链一：campaign 效果**
这个 campaign 做得怎么样 → 曝光多少，然后呢 → 带来多少线索或转化 → 获客成本多少 → 预算多少，这个成本在行业里算什么水平 → 预算砍一半你怎么做
分水岭：第 3 层（报不出后链路，说明只看曝光）

**链二：KOL / 投放**
怎么选的达人 → 除了粉丝量还看什么 → 怎么判断数据有没有水 → 复投了吗 → 哪个达人 ROI 最高，为什么
分水岭：第 3 层（判不出水分，说明没盯过投放）

**链三：公关 / 危机**
遇到过负面吗 → 当时怎么处理的 → 谁拍的板，你做了什么 → 结果如何 → 事后有没有建立机制
分水岭：第 3 层（分不清自己做的和领导拍的）

## 专业性检验点

- 你经手的年度预算大概多少，怎么分配的
- CPM、CPC、CPL、ROI 你日常盯哪个
- 投放平台各自的特点和适用场景
- 品牌类项目怎么衡量效果，用什么替代指标
- 和代理公司怎么合作，比稿、结算、KPI 怎么定
- 公关：媒体资源怎么维护的，通稿和深度稿的差别
- 讲一个你认为成立的创意，为什么成立，数据支持吗
- 代理公司做的部分和你做的部分，边界在哪

## 按企业性质调整

- 大厂：效果导向强，一路追到转化和成本
- 创业：预算极紧，重点问低成本获客和自然流量
- 国企银行：合规和口径审批是核心，对外发声流程比创意重要
- 外企：全球品牌规范、本地化尺度、总部对齐是高频考点
