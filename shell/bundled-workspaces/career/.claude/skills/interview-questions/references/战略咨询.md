# 战略咨询出题手册（精简版）

> 涵盖：MBB / Big 4 Strategy / 大厂战略部 / 投资战略 / 行业研究

## 面试官在验什么

1. **结构化思维**：case 面试考的是拆解方式不是标准答案。
2. **假设是否合理与数字感**：信息不全时能否给出站得住的假设并说明依据；估算题里量级错了比算错更严重。
3. **能不能被引导**：面试官给提示时接不接得住，是协作能力的直接体现。

## 高频追问链

**链一：case 推进**
（给出题目）→ 你先澄清了什么 → 框架是怎么想出来的 → 这一支为什么重要 → 数据支持你的判断吗 → 所以你的建议是什么
分水岭：第 2 层（硬套 4P/SWOT/波特五力，模板化是最重的失分）

**链二：PEI / 个人经历面**
讲一次你影响他人的经历 → 对方一开始为什么不同意 → 你具体说了什么 → 结果怎么样 → 现在回头看还能怎么做
分水岭：第 3 层（追到第三层没细节，说明故事笼统；MBB 一个故事能追十几层）

**链三：行业判断（投资 / 行研）**
你怎么看这个行业 → 依据是什么数据 → 数据来源可靠吗 → 和市场共识的差异在哪 → 如果反方观点成立，你的判断怎么变
分水岭：第 4 层（说不出和共识的差异，观点是搬来的）

## 专业性检验点

- 出一道市场规模估算题，看量级和拆解路径（如某城市一年消耗多少杯咖啡）
- 出一道利润下滑诊断题，看是否先澄清边界再拆
- 给一个你刚列的框架挑一支，问"为什么这支重要，不重要可以砍吗"
- 中途给一个提示，看是否接住并调整
- 要求在限定时间内收口给出明确建议
- 对一个行业观点抛反方意见，看能否接住
- PEI：对方的原话是什么，他为什么反对
- 交付物页数之外，你的关键发现是什么，被采纳了吗

## 按企业性质调整

- 大厂战略部：更关注业务理解和内部推动能力，纯 case 比例低
- 创业：问在数据极少时怎么做判断、怎么验证
- 国企银行：政策口径、风险边界、服务规划，不把方向性判断写成确定承诺
- 外企 / MBB：case + PEI 双线，PEI 追问深度是最大差异点，英文面常见
